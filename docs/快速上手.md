## 1. 这是什么

Cocoa 是 C 系方言语言编译器，双后端输出：

- **Native**：自研 x86/x64 汇编 + PE（零依赖，纯自研）
- **IL**：自研 ECMA-335 编码器 + 元数据（产出 .NET 托管 exe/dll）
- 另有 **Evaluator**（解释执行，REPL 与调试器基础）与 **`.coa` 程序集**（语义层序列化，跨后端库消费）

方言按扩展名分派：`.co`（Cocoa 主方言）、`.cs`（C# 子集方言）。最终目标是**用 Cocoa 自举编译器**（阶段 7）。

## 2. 取得并构建

```bash
# 1) 构建编译器 + 标准库（.coa 产物收至 src\Cocoa.Cs\libs\）
dotnet build src\Cocoa.Cs\Cocoa.Compiler
tools\build-stdlib.cmd

# 2) 便捷入口（仓库根 cocoa.cmd / repl.cmd，Windows）
cocoa --version
cocoa -i                      # 交互式 REPL
```

## 3. 第一个程序

`hello/main.co`：

```co
using System

function Greeting(name: string): string
{
    return "Hello, " + name + "!"
}

function Main()
{
    Console.WriteLine(Greeting("Cocoa"))
}
```

运行：

```bash
cocoa hello/main.co                 # 默认 exe 并运行（native 后端）
cocoa hello/main.co -b dotnet       # IL/native 后端切换
```

输出：`Hello, Cocoa!`

## 4. 单文件 vs 工程

```bash
cocoa hello.co                # 单文件：直接编译（隐式 Main 入口）
cocoa new console MyApp       # 脚手架：生成 MyApp.coproj + main.co
cocoa build -p MyApp.coproj  # 工程构建
cocoa run -p MyApp.coproj    # 构建并运行
cocoa new csharp CsApp        # C# 方言工程（.coproj，.cs 文件）
```

工程格式（.coproj）见 [项目格式规范](项目格式规范.md)。

## 5. 语法速览（10 分钟）

```co
// 类型：i8..i64 / u8..u64 / f32 / f64 / bool / char / string / void / any
var count: i32 = 1                  // 类型显式（.co 类型后置）；var/let 可推断
let name = "Cocoa"                  // let 不可变，var 可变
const MAX = 100                     // 编译期常量

// 函数：返回类型在标冒号之后
function Area(w: f64, h: f64): f64
{
    return w * h
}

// 控制流：if/else、while、for i = a to b [step]、foreach、switch + when
for var i = 1 to 10
{
    if i % 2 == 0
    {
        // ...
    }
}

// 类 / 继承 / 接口 / 属性 / 事件
class Base
{
    public var _v: i32
    protected function Get(): i32 { return _v }
}

class Derived extends Base
{
    constructor(v: i32) { base(v) }
    public property Value: i32 { get return _v set _v = value }
}

// 泛型集合（编译期单态化）
var list = new List<i32>()
list.Add(1); list.Add(2); list.Add(3)

var dict = new Dictionary<string, i32>()
dict["a"] = 1
if dict.TryGetValue("a", out var v) { /* ... */ }

// 函数类型 / Lambda / 委托
var op: (i32, i32) -> i32 = (a, b) => a + b
delegate int Handler(int x);          // .cs 拼写
var h: Handler = x => x * 2
Console.WriteLine(h(21))              // 42

// 异常
try
{
    // ...
}
catch (ex: Exception)
{
    throw ex
}
finally
{
    // ...
}
```

完整语言参考见 [语法手册](语法手册.md)；`.co`/`.cs` 拼写对照见 [语法对照表](语法对照表.md)。
