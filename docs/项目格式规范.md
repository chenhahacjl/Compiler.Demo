# Cocoa 项目格式规范

> 适用范围：`.coproj`（项目文件）、`.cosln`（解决方案文件）、`.coproj.user`（用户级覆盖）、`.coa`（Cocoa 程序集）、增量构建缓存。
> 状态：✓ 已落地（SDK-style XML 格式；`.coa` 程序集格式与依赖清单见 §4）。
> 格式版本：`Version="1"`（读取侧校验，未知版本报错）。

---

## 1. 设计原则

- **对齐现代 .NET**：仿 SDK-style `.csproj`（属性组 + ItemGroup）+ `.slnx`（解决方案），XML 表达，可手写、可 diff、可库解析（`System.Xml.Linq`）。
- **显式语言**：`<Language>` 必填，`Cocoa`（`.co`）或 `CSharp`（`.cs`）；单语言项目，混排报错（语法手册 §46.1）。
- **默认值守卫**：默认属性用 `<X Condition="'$(X)' == ''">默认</X>` 表达（MSBuild 惯用法），外部值自然让位。
- **条件属性**：`PropertyGroup`/`ItemGroup` 支持 `Condition` 最小子集，构建末期按目标求值。
- **容忍与预留**：未知元素 / 未知 `Label` / `Condition` 一律忽略或保留（round-trip 保真），IDE 可自由扩展。
- **确定性**：相同输入 → 相同输出；相对路径基于文件自身目录。

## 2. `.coproj` 项目文件

### 2.1 文件结构与样例

```xml
<Project Version="1">
  <!-- 语言（必填） -->
  <PropertyGroup Label="Language">
    <Language>Cocoa</Language>               <!-- Cocoa | CSharp -->
  </PropertyGroup>

  <!-- 程序集 -->
  <PropertyGroup Label="Assembly">
    <AssemblyName>Interop</AssemblyName>
    <RootNamespace>Interop</RootNamespace>
    <Title>Cocoa Interop Sample</Title>
    <Description>Native import + coa 引用示例</Description>
    <Company>ACME Corp</Company>
    <Product>Interop</Product>
    <Authors>Jane Doe</Authors>
    <Copyright>Copyright (c) 2026</Copyright>
    <AssemblyVersion>1.2.0</AssemblyVersion>
    <FileVersion>1.2.0</FileVersion>
    <ProjectGuid>d1520329-3483-4c02-8f69-34928aea18ed</ProjectGuid>
  </PropertyGroup>

  <!-- 目标 -->
  <PropertyGroup Label="Target">
    <TargetOS Condition="'$(TargetOS)' == ''">Windows</TargetOS>
    <Platform Condition="'$(Platform)' == ''">AnyCPU</Platform>
    <Prefer32Bit Condition="'$(Prefer32Bit)' == ''">false</Prefer32Bit>
    <TargetFramework Condition="'$(TargetFramework)' == ''">net48</TargetFramework>
  </PropertyGroup>

  <!-- 产物 -->
  <PropertyGroup Label="Output">
    <OutputType Condition="'$(OutputType)' == ''">Executable</OutputType>
    <StartupObject>Interop.Main</StartupObject> <!-- Main / Class.Method / Namespace.Class.Method -->
    <Subsystem Condition="'$(Subsystem)' == ''">Console</Subsystem>
    <RequestedExecutionLevel Condition="'$(RequestedExecutionLevel)' == ''">AsInvoker</RequestedExecutionLevel>
    <ApplicationIcon>app.ico</ApplicationIcon>
  </PropertyGroup>

  <!-- 构建 -->
  <PropertyGroup Label="Build">
    <Configuration Condition="'$(Configuration)' == ''">Debug</Configuration>
    <OutputPath Condition="'$(OutputPath)' == ''">out</OutputPath>
    <DocumentationFile>doc.xml</DocumentationFile>
    <TreatWarningsAsErrors>false</TreatWarningsAsErrors>
    <Optimize>false</Optimize>
  </PropertyGroup>

  <!-- 条件分化（示例） -->
  <PropertyGroup Condition="'$(Configuration)' == 'Release'">
    <Optimize>true</Optimize>
    <OutputPath>lib\rel</OutputPath>
  </PropertyGroup>
  <PropertyGroup Condition="'$(Platform)' == 'x86'">
    <Prefer32Bit>true</Prefer32Bit>
  </PropertyGroup>

  <!-- 项 -->
  <ItemGroup>
    <Source Include="*.co" />
    <Reference Include="../Libs/MyLib.coa" />
    <Import Include="kernel32.dll" />
    <Content Include="assets/**" CopyToOutput="true" />
  </ItemGroup>
</Project>
```

### 2.2 分组（`PropertyGroup Label`）

| 分组 | 含义 | 属性 |
|------|------|------|
| `Language` | 项目语言（必填） | `Language` |
| `Assembly` | 程序集元数据 | `AssemblyName` `RootNamespace` `Title` `Description` `Company` `Product` `Authors` `Copyright` `AssemblyVersion` `FileVersion` `ProjectGuid` |
| `Target` | 目标平台 | `TargetOS` `Platform` `Prefer32Bit` `TargetFramework` |
| `Output` | 产物形态 | `OutputType` `StartupObject` `Subsystem` `RequestedExecutionLevel` `ApplicationIcon` |
| `Build` | 构建配置 | `Configuration` `OutputPath` `DocumentationFile` `TreatWarningsAsErrors` `Optimize` |

分组仅作可读性/IDE 组织，不参与语义（同组内重复键后者覆盖，跨组亦然，均按文档序）。

### 2.3 属性表

| 属性 | 取值 | 默认 | 说明 |
|------|------|------|------|
| `Language` | `Cocoa`\|`CSharp` | **必填** | 项目语言；单向校验：Cocoa→源仅 `.co`，CSharp→仅 `.cs`，混排报错 |
| `AssemblyName` | 字符串 | 项目文件名（无扩展） | 产物名（`<AssemblyName>.exe/.dll/.coa`） |
| `RootNamespace` | 字符串 | — | 默认命名空间（预留） |
| `Title`/`Description`/`Company`/`Product`/`Authors`/`Copyright` | 字符串 | — | 程序集元数据（发射预留） |
| `AssemblyVersion` | `x.y.z` | — | 程序集版本（IL 元数据/native 版本资源，发射预留） |
| `FileVersion` | `x.y.z` | — | 文件版本（Win32 版本资源，发射预留） |
| `ProjectGuid` | GUID | — | 项目唯一标识（IDE / 未来分发） |
| `TargetOS` | `Windows`\|`Linux` | `Windows` | 目标 OS（native；当前 native 仅 Windows，Linux 预留） |
| `Platform` | `x86`\|`x64`\|`AnyCPU` | `AnyCPU` | 目标架构；`AnyCPU` 原生后端构建报「请显式 --platform x86/x64」 |
| `Prefer32Bit` | `true`\|`false` | `false` | 仅 `AnyCPU` 有意义（IL 写 32BITPREFERRED；预留） |
| `TargetFramework` | `net40`\|`net48`\|`net8.0`\|`net9.0` | `net48` | 目标框架（dotnet 后端） |
| `OutputType` | `Executable`\|`Library`\|`Cocoa` | `Executable` | 输出类型：`Cocoa` = `.coa` 语义层程序集 |
| `StartupObject` | `Main`/`Class.Method`/`Namespace.Class.Method` | `Main` | 入口；`Executable` 有效 |
| `Subsystem` | `Console`\|`Windows` | `Console` | PE 子系统（native，预留） |
| `RequestedExecutionLevel` | `AsInvoker`\|`HighestAvailable`\|`RequireAdministrator` | `AsInvoker` | 管理员运行（native/布局，预留） |
| `ApplicationIcon` | 路径 | — | 应用图标（相对项目；native 资源，预留） |
| `Configuration` | `Debug`\|`Release` | `Debug` | 构建配置；可由 `--debug/--release` 覆盖（原 `debug`） |
| `OutputPath` | 路径 | 项目目录 | 输出目录（相对项目文件） |
| `DocumentationFile` | 路径 | — | 文档注释输出（预留） |
| `TreatWarningsAsErrors` | `true`\|`false` | `false` | 告警提升为错误（预留） |
| `Optimize` | `true`\|`false` | `false` | 优化开关（预留） |

### 2.4 默认值守卫（MSBuild 惯用法）

预定义变量求值顺序：`CLI 覆盖 ?? .user 覆盖 ?? 文件值（含守卫默认） ?? 解析器兜底默认`。

```xml
<Platform Condition="'$(Platform)' == ''">AnyCPU</Platform>
```

即外部（`cocoa build --platform x64`）提供时采用外部值；否则取文件默认。

### 2.5 `Condition` 表达式

- 位置：`PropertyGroup` / `ItemGroup` 元素上；不作用于单个属性/项。
- 语法：`'$(X)' == 'v'` / `!= 'v'` / `and` / `or` / `!` / 括号（大小写不敏感）
- 变量：预定义 `Configuration` `Platform` `TargetFramework` `TargetOS` `OutputType` + 文件内已定义的任意属性
- 求值时机：CLI / `.user` 覆盖合成之后（构建末端），文档序逐组判定，条件真则生效、重复键后者覆盖
- 对 `Condition` 不做提前求值，作为保留属性参与 round-trip

### 2.6 ItemGroup 项

| 项 | `Include` | 属性 | 说明 |
|----|-----------|------|------|
| `Source` | glob | — | 源文件（`.co`/`.cs`），必须至少一项；支持 `*` `**` 通配 |
| `Reference` | 路径 | — | `.coproj` 项目引用（自动递归构建）/ `.coa` / `.dll` |
| `Import` | DLL 名 | — | native导入表（构建仅警告，见互操作手册） |
| `Content` | glob/文件 | `CopyToOutput` | 非源码部署文件，复制到输出目录（部署接线预留） |

### 2.7 项目引用（`Reference` 中 .coproj）

1. 加载并校验被引用项目：` output = Cocoa/Library`（`Executable` → 错误）；
2. 自动递归构建（采用自身配置；构建期分发配置自当前环境继承）；
3. 产物复制到当前项目生成目录（`cocoa`→`.coa`；`library`→`.dll`）；
4. 消费者以复制后的产物参与编译（`.coa` 语义合并 / `.dll` 元数据引用）；
5. CLI `-r` 同语义。

### 2.8 glob 模式

| 模式 | 匹配 |
|------|------|
| `*.co` | 当前目录所有 `.co` |
| `src/**/*.co` | 递归 |
| `src/*.co` | 一层 |
| `main.co` | 单文件 |

## 3. `.cosln` 解决方案文件

```xml
<Solution Version="1">
  <Project Include="src/Core/Core.coproj" />
  <Project Include="src/App/App.coproj" />
</Solution>
```

| 元素 | 用途 |
|------|------|
| `Solution`（根，`Version="1"`） | 解决方案 |
| `Project`（`Include` 相对路径） | 项目文件引用，每行一个 |

**编译顺序**：由引用关系拓扑排序；无依赖按声明顺序，循环依赖报错。`.coa` 项目无入口；`coco`/`library` 项目不参与顺序（与旧版一致）。

## 3.1 `.coproj.user` 用户级配置（IDE 预留）

同一目录下的 `<项目文件名>.coproj.user`，仅本地、gitignored，保存个人覆盖。XML 同 `.coproj` 根（`<Project Version="1">`）。

### 可覆盖的键

| 层 | 键 |
|----|-----|
| 顶层 | `AssemblyName` / `OutputType` / `Platform` / `TargetFramework` / `TargetOS` |
| Build | `Configuration` / `OutputPath` |

### 优先级

```
.coproj 文件值 < .coproj.user 覆盖 < 命令行参数（--platform/-o/--debug/--release/--no-incremental）
```

### IDE 预留契约

- `ItemGroup` 在 `.user` 中不生成（项目形状由共享文件决定）；
- 未知 `PropertyGroup` 键 / 未知元素 / 未知 `Label` 一律忽略不报错；
- 已知键的非法值抛 `ProjectFileFormatException`（含行号）；
- `.cosln.user` 列为后续预留。

## 4. `.coa` 程序集格式

`.coa` 是 Cocoa 的**程序集**分发格式（等价 .NET dll 语义）：每库一个或多个 `namespace`，**无入口点**、公共符号表按命名空间组织；**内容为语义层 `BoundProgram`（降级绑定树 + 符号表）序列化**，而非 native 三地址/IR——只有语义层才能驱动 native（`BoundTreeToIr`）与 IL（`IlEmitter`）双后端通用，对应 .NET 的 IL 程序集概念：

| 部分 | 内容 |
|------|------|
| 头 | 魔数 `COCOA` + 版本 + 平台要求 + **backend 要求（`requires`）** |
| 依赖清单（manifest） | 引用的 .NET 程序集列表 + `import` 的 native DLL 列表 + 被引用的 `.coa` 列表 |
| 公共符号表 | 导出的 public 类型/函数/枚举/全局变量（按命名空间组织） |
| 代码表 | 序列化的 `BoundProgram`（函数体 + 类成员，后端无关） + 私有依赖闭包（公共符号传递引用的私有函数/类型/字符串常量） |

- 由 `output = Cocoa` 项目产出（编译到 BoundProgram 即停，不产出 IR/机器码/IL）；通过 `[references]` / `-r` 引用，编译器加载后**合并编译**，消费方按自己的后端/平台产出独立 dll/exe；
- **无入口点**：`output = Cocoa` 源码须含 `namespace`，禁止 `Main`/入口（违者编译报错）；
- **backend 要求推导**（`-f cocoa` 发射时扫描库内容）：含 .NET API 或 OOP（class 实例/继承）→ `requires: dotnet`；含 native import → 绑定平台、双后端可用；纯函数 + 基础类型 → `requires: any`（双后端通用）；
- 消费方后端与 `requires` 不匹配 → **编译期报错**（如 native 消费 `requires: dotnet`）；
- 与 `-f dll`（native 导出库）互斥：`cocoa` 是编译期合并，`dll` 是运行期导入；
- 平台无关：纯 Cocoa 代码跨平台；含 native import 时绑定平台（消费方平台不匹配报错）；
- **`fn` 符号 + `ns`（函数命名空间）字段**：读侧校验版本，旧库需重新编译；消费改为命名空间 only 注入（`using MyLib;` 或 `MyLib.Func(...)`）。

### 4.1 依赖清单（manifest）

`.coa` 头部声明依赖与约束，消费方编译器加载 `.coa` 时自动传递：

| 依赖类型 | 声明内容 | 消费方行为 |
|---------|---------|-----------|
| backend 要求 | `requires: dotnet` / `native` / `any`；平台要求 | 消费方后端/平台不匹配 → 编译期报错 |
| .NET 程序集 | 程序集名 + 版本（等价 AssemblyRef 清单）| 加入消费方引用集（IL 路径 → AssemblyRef 表） |
| native DLL | DLL 名列表 | 合并 `import` 声明（→ 导入表） |
| `.coa` 程序集 | 被引用的 `.coa` 路径/标识 | **递归加载**（防循环 + 去重，同一 `.coa` 只加载一次） |

- 缺清单的 `.coa`（纯 Cocoa 基础类型代码）不要求此节，`requires` 默认 `any`
- 增量缓存须按**传递**依赖哈希失效（A→B→C，C 变则 A 失效）

### 4.2 与 .NET 组合能力

| 消费方产物 | 导入 `.coa` | 结果 |
|-----------|------------|------|
| `-f exe`（IL 路径，netcore） | ✓ | .NET 托管程序（原生 apphost `x.exe` 直接运行 / `dotnet x.dll`） |
| `-f exe`（IL 路径，netfx `--dotnet-runtime net4x`） | ✓ | .NET Framework 托管程序（Windows 直接运行 `x.exe`） |
| `-f dll`（IL 路径） | ✓ | .NET 库，可被其他 .NET 程序引用 |
| `-f exe` / `-f dll`（Native，`requires: any` 或含 native import） | ✓ | 原生 PE |
| Native + cod 调用 .NET 调用（`requires: dotnet`） | ✗ 编译期报错 | 需 CLR Hosting |

## 5. 增量构建

增量是构建工具内置行为（`BuildCache`），**不是项目文件格式暴露的属性**（`--no-incremental` 关闭）。

- 缓存集中于 `<解决方案/项目目录>/.cocoa/<name>.cache`
- 命中判定：源文件哈希 + 引用/imports + 构建选项快照（`format/platform/backend/configuration/output/entry/dotnetRuntime`）
- `--no-incremental` 关闭

## 6. 错误与诊断

| 场景 | 处理 |
|------|------|
| 文件不存在 | `FileNotFoundException` |
| XML 语法/结构非法 | `ProjectFileFormatException`（含行号，`IXmlLineInfo`） |
| 缺少 `<Language>` | 格式异常 |
| `Language` 与源列举不一致（`.cs` in Cocoa / `.co` in CSharp） | 编译期报错（逐文件扩展名校验） |
| missing `<Source>` | “至少一个源模式”异常 |
| 缺失 `Source` 命中 | 告警 |
| 循环依赖 / 引用循环 | 错误 + 环路报告 |
| `Version != 1` | 读取侧「不支持的格式版本」异常 |
| `ProjectGuid` 非法 | 格式异常 |
| `Platform=AnyCPU` + native 后端 | 错误：指定 `--platform x86/x64` |
| 引用 `Executable` 项目 | 错误（仅 `Cocoa`/`Library` 可被引用） |
| Refer 文件类型未知 | 错误 |
| `Content`/`Metadata` 未接线系统 | 解析进模型，构建暂忽略 |

当前不在范围内：`PackageId`、`RepositoryUrl`、`DefineConstants`、`NoWarn`、`LangVersion`、`BaseIntermediateOutputPath`。
