## 1. 程序结构

一个 Cocoa 程序由一个或多个源文件组成。每个源文件可以包含：

- `using` 导入指令
- 命名空间声明（内含类型、函数声明等）
- 全局语句（脚本模式）
- 函数声明
- 类声明
- 接口声明
- 枚举声明

**全局语句模式**：
```
print("Hello World")
```

**函数入口模式**：
```
public static Main(): void
{
    print("Hello World")
}
```

也支持带命令行参数的变体：
```
public static Main(args: string[]): void
{
    print(args[0])
}
```

**两种模式互斥**：一个程序不能同时包含全局语句和 `Main` 函数。

**命名空间模式**：
```
using System

namespace MyApp
{
    public class Program
    {
        public static Main(): void
        {
            Console.WriteLine("hello")
        }
    }
}
```

## 7. 变量声明

```
let name: string = "hello"
```

### 9.4 二元表达式 (✅)


### 9.5 三元表达式 (✅)

```
cond ? trueValue : falseValue
```

示例：
```
let max = a > b ? a : b
```

右结合，两分支取公共类型（数值自动隐式转换）；三后端均短路求值（`cond ? f() : g()` 只调用被选中分支）。

### 9.6 赋值表达式 (✅)

```
x = 42
x += 10
```

赋值表达式返回被赋的值，可链式：

```
a = b = c = 0
```

### 9.7 调用表达式 (✅)

```

```

### 9.8 成员访问 (🔧)

### 9.9 `new` 表达式 (🔧)

```

```

### 9.10 `this` / `base` 表达式 (🔧)

```

this.field      // 实例字段
this.Method()   // 实例方法
base.Method()   // 调用基类方法（非虚调用）
base()          // 调用基类构造函数
```

### 9.11 `is` / `as` 表达式 (🔧)

```
obj is Circle           // 类型测试 → bool
obj as Circle           // 安全类型转换 → Circle? (null if fails)
```

### 9.12 Lambda 表达式 (🔧)

```
(x: int, y: int) => x + y
() => print("hello")
(x) => x * x
```

### 9.13 `typeof` / `sizeof` (🔧)

```
typeof(int)             // 获取 Type 对象

```

### 9.14 数组索引 (✅)

```
arr[0]
arr[i + 1]
```

仅一维；`arr.Length` 只读属性返回长度；越界为运行时错误（managed 抛异常 / native 打印 `error: array index out of range` 并以退出码 1 终止）。

### 10.6 For 语句

Cocoa 支持两种 for 循环语法。

#### 10.6.1 Cocoa 式 `for-range` (✅)

统一语法：`for [paren] [var ident =] lower to upper [paren] body`，括号与循环变量均可选。

```
// 声明新可变循环变量（推荐）
for var i = 1 to 10
{
    print(i)
}

// 括号可选
for (var i = 1 to 10)
{
    print(i)
}

// 省略 var：复用外层已存在变量（循环后 i 保留终值；未定义或只读 → 编译报错）
for i = 1 to 10
{
    print(i)
}

// 纯次数循环：隐藏计数器，运行 upper - lower + 1 次（for (1 to 10) = 10 次）
for (1 to 10)
{
    print(""hi"")
}
```

循环变量 `i` 在每次迭代开始时自动递增。循环变量只能用 `var` 声明（`let`/`const` 报错）；省略 `var` 时 `i` 必须在外部作用域已定义且可写，否则编译器报错。`for (var i = 5 to 5)` 恰好执行 1 次；`lower > upper` 时 0 次。

#### 10.6.2 C 风格 `for (init; cond; update)` (✅)

```
for (var i = 0; i < 100; i++)
{
    print(i)
}
```

| 部分 | 说明 |
|------|------|
| `var i = 0` | 初始化语句：`var`/`let`/`const` 变量声明，或赋值表达式（变量需已在作用域内） |
| `i < 100` | 条件表达式（每次迭代前检查，`false` 时退出；可省略） |
| `i++` | 更新表达式（每次迭代后执行；`++`/`--` 为全局后缀运算符） |

三个部分都可以省略（`;` 分隔符仍必须）：

```
// 无限循环
for (;;)
{
    break
}

// 仅条件
var i = 0
for (; i < 10;)
{
    i++
}

// 仅更新
for (var i = 0;; i++)
{
    if (i >= 10)
    {
        break
    }
}
```

`break`/`continue` 语义与 C# 一致：`continue` 先执行更新表达式，再检查条件。

### 12.3 继承 (已实现)

```
public class Circle: Shape
{
    private _radius: int

    public constructor(name: string, radius: int): base(name)
    {
        _radius = radius
    }

    public override function Area(): int
    {
        return 3 * _radius * _radius
    }
}
```

- 单继承（`class Foo: Bar`；`extends` 与 `:` 等价，如 `class Foo extends Bar`）
- **多接口实现**（P2 ✅）：`class Foo: Bar, IA, IB`（首个非接口 = 基类，其余须为接口，至多一个非接口基类；`extends` 同样支持）
- 基类构造通过 `base(...)` 调用；`this(...)` 委托本类构造；未显式链时隐式 `base()`（基类需 0 参构造）或默认无参构造
- 构造链前缀支持 `:` 或 `extends` 两种写法：`constructor(...): base(...)` 与 `constructor(...) extends base(...)` 等价
- `virtual`/`override` 多态分派（callvirt）；`abstract` 无方法体；`sealed` 类不可继承
- `base.Method()` 非虚调用基类方法
- 循环继承 / 继承 sealed 类 → 编译期诊断
- **待实现**：`base(...)` 参数校验改进、`sealed` 方法、非抽象类含抽象成员检查

## 22. 命名空间与导入

Cocoa 的命名空间系统用于组织代码并与 .NET 程序集交互。命名空间声明和 `using` 导入仅在编译期影响名称解析。

### 22.1 `using` 导入 (已实现)

`using` 导入将指定命名空间的前缀加入查找路径，使后续代码可以使用非限定类型名称。用于消费 `-r` 引用的外部库类型，也支持导入**同编译内**的命名空间类：

```
using MyLib;
using My.App.Models    // 分号可选，可省略

function Main()
{
    var p = new Point(5)   // 解析为 MyLib.Point（外部）或 My.App.Models.Point（内部）
    print(p.Get())
}
```

- 分号**可省略**：`using MyLib` 与 `using MyLib;` 等价（C# 式写法兼容）
- 名称可为点号多段：`using Foo.Bar;`（C# 式点号限定名）
- 名称解析顺序：当前作用域 → 简单名查已声明类型 → using 前缀拼接（`前缀.名字` 查内部命名空间类 + 引用程序集外部类型）→ 报错

### 22.2 命名空间声明 (已实现)

命名空间声明将包含的类放入指定命名空间：

```
namespace MyLib
{
    public class Point
    {
        private _x: int

        public constructor(x: int)
        {
            _x = x
        }

        public function Get(): int
        {
            return _x
        }
    }
}
```

编译为 library（`output = library`）时，类在 IL 中命名为 `MyLib.Point`，可被其他 Cocoa/.NET 项目 `-r` 引用消费。

### 22.3 完全限定名称 (✅)

完全限定名称无需 `using`，可直接引用任何命名空间下的类型和成员。支持内部类（`Namespace.ClassName`）的静态成员调用/静态字段访问/枚举成员访问：

```
My.App.Program.Main()              // 内部类静态方法（点号全名）
My.App.Utils.Count                 // 内部类静态字段
My.App.Color.Red                   // 内部枚举成员
System.Console.WriteLine("hello")  // 外部类型
System.Math.Max(1, 2)
System.Collections.Generic.List<int>
```

> 边界：`new 命名空间.类(...)`、类型标注 `var p: 命名空间.类`、强转 `(命名空间.类)x` 的点号全名暂不支持（Phase 5 规划中）——这些场景需 `using` 导入后使用简单名。

### 22.4 设计要点

- 命名空间声明必须使用 `{}` 包裹成员列表；名称可为点号多段：`namespace Foo.Bar { ... }`（C# 式，等价嵌套）
- 命名空间内当前支持类声明与函数声明
- 函数声明在命名空间内时，生成的 IL 类使用 `Namespace.ClassName` 全名
- 消费外部库：`-r mylib.dll`（或 coproj `[references]`）→ `using MyLib` → 短名解析
- 名称解析顺序：当前作用域 → using 前缀拼接（`前缀.名字` 查内部类 + 引用程序集）→ 报错
- 命名空间不影响运行时行为，仅在编译期影响名称解析
- `using` 关键字双重用途由位置区分：文件级 `using MyLib` 为导入指令（本§）；块级 `using (var r = ...)` 为资源管理语句（见 §10.14）

## 23. 字符串插值 (✅ 6e-M11 P5b + P5c)

### 23.1 插值语法 (✅)

```
let name = "world"
print($"Hello {name}")

let a = 10
let b = 20
print($"{a} + {b} = {a + b}")
```

- 三种前缀：`$"..."`（普通：单行、字面量段处理 `\` 转义）/ `$@"..."` / `@$"..."`（verbatim：多行原样、不处理 `\`）
- 洞 `{expr}` 可为任意表达式（含嵌套 `{...}`、字符串/注释）；`{{` / `}}` 转义字面花括号；`""` 转义引号
- 洞值转 string（int/byte/bool/char/double/string，显式转换）；降级为字符串 `+` 链，解释器/IL/native 三后端一致；常量折叠不启用

### 23.2 对齐与格式说明符 (✅ 6e-M11 P5c)

```
print($"{42,5}")       // "   42"（右对齐宽 5）
print($"{-42,-6}")     // "-42   "（左对齐宽 6）
print($"{255:X}")      // "FF"（int 十六进制，大写/小写 x）
print($"{3.14159:F2}") // "3.14"（double 定点 2 位）
print($"{1e22:E2}")    // "1.00E+022"（科学计数，指数 3 位补零）
print($"{123456.789:G3}") // "1.23E+05"（通用，-4≤e<p 定点否则科学）
```

- `{expr[, width][: fmt]}`：宽度为有符号整数字面量（正右对齐 / 负左对齐，空格填充）；格式说明符为 `:` 后到洞尾（不含闭合 `}`）的原始文本
- 实现：**解释器/IL** 走 .NET `string.Format("{0:F2}", x)`（Evaluator 同构）；**native** 走自研运行时 `StringFormat`（int D/X + double F/E/G/plain，全 double 范围）
- double 格式语义（native，对齐 .NET）：F 定点 `value×10^n` 大整数舍入（默认 2 位、上限 24）；E 科学（默认 6 位小数、指数 3 位补零）；G 通用（默认 15 位有效数字、指数 2 位补零、剪尾零去尾点）；round-half-away-from-zero；小写 `e`/`g` 小写指数；详见 §43
- 注：native 与 .NET 均为 round-half-away-from-zero（与 `Math.Round` 的 half-to-even 不同，.NET 格式化实际采用 away）

## 43. 浮点类型 double ✅

> 状态：✅ 已实现（阶段 6、6a-5）：`double` 类型全链路（字面量/算术/比较/转换/print/double[]），解释器 + IL + native x86/x64 四路语义一致。

```cocoa
let a = 3.14               // double 字面量（十进制小数）
var d: double = 0.0
print(10.0 / 4)            // 2.5（native 整数结果去小数点）
print(1.0 / 3.0)           // 0.333333（native 定点 6 位舍入剪零）
print(1.0 / 0.0)           // Infinity（IEEE 754 语义）
print(0.0 / 0.0)           // NaN
print(0 - 1.5)             // -1.5（一元负）
print(1.5 < 2.5)           // True
print("d=" + 1.5)          // d=1.5（string + double 拼接）
print((int)2.75)           // 2（显式截断）
var arr: double[] = new double[2] {1.5, 2.5}
print(arr[0])              // 1.5
```

| 特性 | 说明 |
|------|------|
| 字面量 | 十进制小数（`.5`、`1.` 之外的常规形式），词法按 `.` 后跟数字判定，`NumberStyles.Float` 解析；**科学计数法 `e`/`E`（可选 `+`/`-` 指数）**：`1e3`、`1.5e-3`、`1E+10`、`5e-324`、`1e308`（`1e`/`1e+` 等无数字指数不消费，回落 `1` + 标识符）；`f`/`m`/`L` 后缀未实现 |
| 算术 | `+ - * /` 与一元负，IEEE 754 语义（除零得 `Infinity`、0/0 得 `NaN`、负数零 `-0` 保留） |
| 比较 | `==` / `!=` / `<` / `<=` / `>` / `>=`，结果为 bool |
| 转换 | `int → double`、`byte → double` 隐式；`double → int`、`double → byte` 显式（截断）；`double → string` 隐式（print/拼接）与显式 `(string)x`；`double(3)` / `(double)x` 显式转换语法 |
| 混合运算 | `int ± double` 等自动提升为 double；`string + double` 拼接（见 §40） |
| `double[]` | 8 字节元素数组：`new double[n]` / `new double[] {…}` / `new double[n] {…}`、下标读写（native 元素尺寸 8 双槽装载）、`.Length` |
| print 格式（native） | 整数结果去小数点：`10.0 / 4` → `2.5`、`2.5 * 2` → `5`、`123456789.0` → `123456789`；其余定点 6 位舍入剪零：`1.0 / 3.0` → `0.333333`、`2.0 / 3.0` → `0.666667`、`100.0 / 7` → `14.285714`、`0.1 + 0.2` → `0.3`；特殊值：`Infinity` / `NaN` / `-0` / `0`；全 double 范围（~1e-308~1e308，含亚正规） |
| 格式说明符（插值洞 `{x:fmt}`） | F（定点）：`value×10^n` 1280 位大整数定点，round-half-away-from-zero，默认 2 位小数、精度上限 24；E（科学）：尾数 away 舍入、指数 3 位补零（`1.23E+004`）、默认 6 位小数；G（通用）：`-4 ≤ e < p` 定点否则科学、剪尾零+去尾点、指数 2 位补零（`1.23E+05`）、默认 15 位有效数字；小写 `e`/`g` 小写指数；特殊值直出 `Infinity`/`NaN` |
| print 格式（IL） | .NET `Console.WriteLine(Double)` 默认（往返）格式；`(string)2.75` → `2.75` 两后端一致；插值洞 `{x:fmt}` 走 .NET `String.Format`（`E` 默认 6 位、`G` 默认 15 位显式精度） |
| 求值 | 解释器 `Evaluator`、IL `Emitter`、native IR（`DoubleToString` 运行时）均覆盖，常量折叠支持 double 运算与一元负 |

## 44. C# 兼容语法 ✅

> 状态：✅ 已实现（阶段 6）。在保留 Cocoa 语法（`name: Type` 类型后置、`function`/`property`/`constructor` 关键字）的同时，支持 **C# 式类型前置语法**，同一文件/同一类内可混用两种写法。绑定与发射共用同一管道，三条后端（解释器/IL/native）语义一致。

### 44.1 成员声明对照

| 类别 | Cocoa 语法 | C# 语法 |
|------|-----------|---------|
| 字段 | `private _x: int` | `private int _x;` |
| 字段 + 初始化器 | `private _x: int = 5` | `private int _x = 5;` |
| readonly 字段 | `readonly _x: int` | `readonly int _x;` |
| 方法 | `public function Area(): int { ... }` | `public int Area() { ... }` |
| 无返回方法 | `public function SetX(x: int)` | `public void SetX(int x) { ... }` |
| 静态方法 | `public static function Square(x: int): int` | `public static int Square(int x) { ... }` |
| 属性（完整） | `public property Name: string { get { ... } set { ... } }` | `public string Name { get { ... } set { ... } }` |
| 属性（自动） | `public property X: int { get set }` | `public string X { get; set; }` |
| 自动属性 + 初始化器 | `public property X: int { get set } = 42` | `public string X { get; set; } = 42;` |
| 访问器修饰符 | `public property X: int { get private set }` | `public int X { get; private set; }`（访问器可见性须严格比属性更受限，且至多一个访问器可带修饰符） |
| 属性（只读） | `public property Name: string { get { ... } }` | `public string Name { get; }` |
| 表达式体方法 | `public function Area(): int => _x * _y` | `public int Area() => _x * _y;` |
| 表达式体属性 | `public property X: int => _x` | `public int X => _x;`（只读 getter） |
| 构造函数 | `public constructor(x: int) { ... }` | `public Point(int x) { ... }` |
| 构造链 base | `public constructor(r: int): base(n) { ... }` | `public Circle(int r) : base(n) { ... }` |
| 构造链 this | `public constructor(): this(0, 0) { ... }` | `public Point() : this(0, 0) { ... }` |

### 44.2 参数

| 场景 | Cocoa 语法 | C# 语法 |
|------|-----------|---------|
| 普通参数 | `x: int` | `int x` |
| 数组参数 | `arr: int[]` | `int[] arr` |
| 多参数 | `(x: int, y: int)` | `(int x, int y)` |

### 44.3 局部变量

| 类别 | Cocoa 语法 | C# 语法 |
|------|-----------|---------|
| 类型推断 | `var x = 10` | `var x = 10;` |
| 类型标注（无初值，零值初始化） | `var x: int` | `int x;` |
| 类型标注 + 初值 | `var x: int = 10` | `int x = 10;` |

`var` 的 `=` 可省，省了必须有 `: 类型`（否则编译报错）；`let` 不可变变量必须提供初值（Cocoa 独有，C# 无对应物）。

### 44.4 语句分号

C# 式方法体内的语句分号**可选**：`_x = x;`、`return _x * 2;`、`print("hi");` 与无分号写法等价，可在同一方法体内混用；类/接口成员声明末尾的分号同样可选。

### 44.5 接口成员

| 类别 | Cocoa 语法 | C# 语法 |
|------|-----------|---------|
| 方法签名 | `function Area(): int` | `int Area();` |
| 属性签名 | `property Name: string { get }` | `string Name { get; }` |

### 44.6 初始化器与静态构造（.cctor）

字段与自动属性初始化器在构造函数中执行（IL 后端；native 的对象模型后置）：

- **实例字段** `private int _x = 5;`：每个实例构造函数在**构造链（base/this）之后**、函数体之前执行赋值；自动属性初始化器作用于其后备字段 `_X`
- **静态字段** `public static int Max = 100;`：编译器合成 `.cctor` 静态构造器，按声明顺序初始化，首次静态访问/实例化前运行（readonly 静态字段在 `.cctor` 中赋值合法）
- **用户静态构造函数**（6e-M11 P4）：`static Foo() { }`（C# 式）/ `static constructor() { }`（Cocoa 式）直接成为 `.cctor` 符号（编译器不再合成）；静态字段初始化器自动并入其函数体开头，先于用户静态构造体执行；须 0 参、无构造链（base/this）、无可见性修饰符、禁实例访问（this/base/裸实例字段）——违规均报错
- **初始化顺序**：`base()` → 字段初始化器 → 构造函数体；静态：字段初始化器 → 用户静态构造体
- 无静态初始化器且无用户静态构造时不生成 `.cctor`

### 44.7 混用示例

```cocoa
public class Person
{
    private string _name;                 // C# 字段
    private _age: int                     // Cocoa 字段
    public static int Count = 0;          // C# 静态字段 + 初始化器

    public Person(string name, age: int)  // 参数双语法混用
    {
        _name = name;
        _age = age;
        Count = Count + 1;
    }

    public string Name { get; set; }      // C# 自动属性
    public int Age { get; set; } = 18;    // C# 自动属性 + 初始化器
    public property FullName: string { get { return _name } }   // Cocoa 属性

    public function Greet(): string       // Cocoa 方法
    {
        return _name;
    }

    public int GetAge()                   // C# 方法
    {
        return _age;
    }
}
```
