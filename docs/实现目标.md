## 1. 总体架构

```
.co 源文件
    │
    ▼
SourceText ── Lexer ──► Parser ──► Binder ──► Lowerer ──► IR ──► IAssembler ──► PEFile ──► exe/dll
    │        (Token)     (Syntax)   (BoundTree)  (goto-IR)   (三地址码)      (x86/x64)   (写入器)    （Native 路径）
    │
    └──────────► (BoundTree) ──► Emitter ──► (IL 编码器 + ECMA-335 元数据) ──► 托管 PE ──► exe/dll
                                                                                     （IL 路径）
```

| 层 | 位置 | 说明 |
|----|------|------|
| 前端 | `src/Cocoa/CodeAnalysis/Syntax/`、`Binding/` | Lexer/Parser/Binder/Lowerer，两路径共用 |
| IR | `Emit/IR/`（阶段 1-3 新增） | 三地址码 + 虚拟寄存器，两后端共用 |
| Native 后端 | `Emit/Native/` | NativeCodeEmitter、IAssembler、X86/X64 汇编器、PEFile 全套 |
| IL 后端 | `Emit/IL/`（编码器+元数据写入器）、`Emit/Emitter.cs` | 自研（阶段 5 完成）；IL 路径互操作走 ImplMap（5-5 落地） |
| 运行时 | `Emit/Native/Runtime/` | Windows x86/x64 运行时（阶段 4 合并 IR 化） |

**关键原则**：

1. **零第三方依赖**（最终）：仅保留 `System.Collections.Immutable`；移除 Mono.Cecil、Mono.Options
2. **双后端对称**：Native（自研）与 IL（自研后）能力对齐
3. **IR 为分水岭**：语言特性只需写到 IR，双后端自动获得
4. **严格顺序**：阶段 0（修 bug）→ IR → 运行时 → IL 自研 → 语言/互操作/项目 → 自举

## 2. 编译器前端

### 2.1 管道

```
SourceText (字符序列 + 行列映射)
    ▼
Lexer    → Token（含 trivia：空白/注释/换行）
    ▼
Parser   → SyntaxTree（不可变；precedence climbing 表达式；GetChildren 源生成器）
    ▼
Binder   → BoundTree（符号解析 + 类型检查 + 常量折叠；DiagnosticBag 报错）
    ▼
Lowerer  → 底层 goto-IR（if/while/for/三元/复合赋值全部降低；RemoveDeadCode）
```

### 2.2 语言现状（v0.2 状态）

| 类别 | 内容 |
|------|------|
| 类型 | `int` `bool` `string` `double` `void` `any` |
| 变量 | `let`（不可变）/ `var`（可变），类型推断 |
| 运算符 | 算术、比较、逻辑、位、赋值（含复合） |
| 语句 | `if/else` `while` `do-while` `for i = a to b` `break` `continue` `return` `{ }` |
| 函数 | `function` 声明/调用、递归 |
| 内置 | `print` `input` `random` |

扩展计划（阶段 6）：`record`、动态数组、`byte[]`、字符串索引/子串/比较、`enum`、多文件模块、泛型、`import`/`export`。状态以 `docs/语法手册.md` 标记为准。

### 2.3 类型系统

- `TypeSymbol` 单例体系（Error/Any/Boolean/Int32/String/Void 等）
- 阶段 6 重构为抽象基类 + 子类（Primitive/Array/Enum/Generic...），支撑互操作与泛型

## 3. IR 层

> 阶段 1-3 落地；详细设计见 `docs/IR设计.md`（当前为草案）

| 决策 | 内容 |
|------|------|
| 形态 | 三地址码：指令 = 操作码 + 目的虚拟寄存器 + ≤2 个操作数 |
| 寄存器 | 虚拟寄存器无限，后端分配物理寄存器/栈槽 |
| 覆盖 | 常量、mov、算术/逻辑/比较、分支/标签、call、栈操作、内存读写 |
| 打印器 | 文本 IR（测试断言 + `.cod` 程序集输出基础） |
| 外部符号 | 调用目标可为：IR 函数 / .NET 元数据引用 / native 导入（`docs/IR设计.md` §2.1） |
| 映射 | IR → IAssembler 后端（x86/x64 共用）；严格复刻现有 ABI 语义 |

**收益**：语言特性只写一次（到 IR）；`.cod` 程序集 = IR 序列化（编译期合并，native/IL 通用）；x86/x64 差异收敛到指令选择。

## 4. Native 后端

### 4.1 组成（全部自研，零依赖）

| 组件 | 位置 | 说明 |
|------|------|------|
| NativeCodeEmitter | `Emit/Native/NativeCodeEmitter.cs` | 薄壳：绑定树 → IR（BoundTreeToIr + RuntimeEmitterIR）→ IAssembler（阶段 2-4） |
| IR 层 | `Emit/IR/` | 三地址码 + 虚拟寄存器（BoundTreeToIr/IrToAssembler/RuntimeEmitterIR/IrPrinter 等） |
| IAssembler | `Emit/Native/Assembler/IAssembler.cs` | 平台无关汇编抽象 |
| X86Assembler / X64Assembler | `Emit/Native/Assembler/X86/X86Assembler.cs` 等 | 指令编码 + 重定位 |
| PEFileWriter | `Emit/Native/PEFile/PEFile.cs` | PE 写入（.text/.data/.idata 三 section） |
| 运行时 | `Emit/IR/RuntimeEmitterIR.cs` | 内建函数统一 IR 生成（阶段 4 合并 x86/x64 双份实现） |
| 导入解析 | `ImportResolverStubEmitterX86.cs` 等 | 导入表生成（阶段 6 完整化） |

### 4.2 ABI（x86）

- 栈式求值：`NativeCodeEmitter` 用 eax/rax 作为临时结果寄存器，栈保存中间值
- 调用约定：stdcall 风格，栈传参、栈平衡
- 入口 stub → `main`；运行时函数通过导入表调用（GetStdHandle/ReadConsoleW/WriteConsoleW 等）
- x86 输出显式 `RelocsStripped`（无重定位表）；阶段 6 的 dll 输出需补写侧重定位

### 4.3 已知问题（阶段 0）✅ 已修复（2026-08-13）

x86 下管道输入 "123\r\n" 崩溃（0xC0000005）：根因不在 `Runtime.X86.cs`，而是自举导入 stub
（`ImportResolverStubEmitterX86.cs`）的名字匹配只比较导出名前 8 字节，`WriteConsoleW` 被解析成
`WriteConsoleA`，IAT 槽误填，控制台路径跳入 kernel32 导出名字表触发取指违规。
黑盒对照（TinyCC/gcc + objdump + 自研调试器 debughost）定位并双平台（x86/x64）对称修复；
`ImportResolverTests` 回归防护。详见 `docs/开发计划.md` 阶段 0 结论。

|------|---------------|
| Mono.Cecil + Mono.Options | 自研 IL 编码器 + ECMA-335 元数据写入器 + 托管 PE 写入器 |

## 10. 自举设计

```
阶段 7：编译器组件按依赖序用 Cocoa 重写（Lexer → ... → IR → 后端）
        Native 与 IL 双路径均自举；编译器只依赖阶段 6 语言特性
阶段 8：Stage0（C# 编译器 → B0）→ Stage1（B0 编源码 → B1）→ Stage2（B1 编源码 → B2）
        验证 B1 ≡ B2
```

- 语言面自举无需 .NET 反射：Cocoa 编译器需要 import/record/泛型等（阶段 6 提供）
- 自举后 C# 宿主仅保留引导角色

## 11. 代码模式规范

所有新代码**必须遵循**既有模式：

| 模式 | 要点 |
|------|------|
| 不可变语法树 | `sealed partial class`、get-only 属性、内部构造函数、`GetChildren()` 源生成器 |
| 不可变 BoundNode | 内部密封类、`Kind` 属性、表达式实现 `Type` |
| BoundNodeFactory | Lowerer 用工厂方法（`Block/Goto/Label/...`），不直接 new |
| ImmutableArray | 子节点列表一律 ImmutableArray + Builder |
| DiagnosticBag | 每个诊断一个 `ReportXXX` 方法，统一走 `ReportError` |
| TypeSymbol | 单例 + 静态字段（阶段 6 改为抽象基类 + 子类） |
| 循环依赖 | 目录/命名空间单向依赖：Syntax ← Binding ← Emit |
