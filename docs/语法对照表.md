# Cocoa ↔ C# 方言语法对照表

> **定位**：`.co`（严格纯 Cocoa 方言）与 `.cs`（严格 C# 方言）共享表达式引擎 / Binder / 三后端，按扩展名分派（6e-M15）。
> **列含义**：`语法` = 该行的完整写法（含分号有无）；`.co 写法` / `.cs 写法` = 该写法在对应方言是否支持（✔ 支持 · ✖ 拒绝）。每种拼写变体单独一行。
> 双方言均拒绝的拼写（无关键字顶层函数、类型前置省略分号、无 var foreach 等）已从表中删除。
> 修饰符顺序照搬 C#：语法自由不强制，约定 `[访问权限] [static] function/property/constructor/class/interface`。
> 语义见 `docs/语法手册.md`；`.cs` 严格规则见 §46。

## 18. 小结

| 方言 | 专属 / 拒绝清单 |
|------|----------------|
| `.co` 专属（`.cs` 拒绝） | `function`/`property`/`constructor` 关键字、`extends` 继承、`name: Type` 参数/字段/局部类型后置、`let`、`const x = 10`（无类型/类型后置）、`for i = 0 to n` 次数循环（含 `step`）、`foreach (var x in ...)`、`import`/`stdcall`/`cdecl`、省略分号、if/while/switch/foreach/do-while 无括号条件、接口 `function`/`property` 关键字成员、Cocoa 式属性 |
| `.cs` 专属（`.co` 拒绝） | 类型前置声明（参数/局部/字段/返回类型）、C# 式成员（`public int Area()` / `public int X { get; set; }` / `public Foo(...)` / `static Foo()`）、`class Foo: Base` 冒号继承、C# 风格 `for (;;)`、`public static void Main()`、分号必选 |
| 两方言共用 | 注释、字面量（含 verbatim/raw/`@` 标识符）、类型、运算符、表达式、`else`、`switch`/`case`/`when`、类/接口/枚举、插值、命名空间、内置函数 |
| 双方言均拒绝 | 无关键字顶层函数（`Main(): void`）、类型前置省略分号（`int x`/`private int _x`/`const int x`）、`foreach (x in ...)` 无 var、接口方法签名无分号 |
