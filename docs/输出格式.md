# Cocoa 输出格式规范

> 适用范围：`-f exe` / `-f dll` / `-f cod` 三种输出
> 状态：`exe` 已实现（Native/IL）；`dll`、`cod` 设计中（阶段 6b）
> 最后更新：2026-08-13

---

## 1. 总览

| 格式 | 输出物 | 用途 | 消费方式 |
|------|--------|------|---------|
| `exe` | PE 可执行文件（Native 或 IL 程序集） | 独立运行 | 直接执行 |
| `dll` | Native 导出库（导出表 + 重定位） | 被其他程序/库调用 | 运行期 `import` → 导入表 |
| `cod` | IR 序列化库 | Cocoa 内部库分发 | 编译期 `[references]` 合并 |

```bash
coc build -p foo.coproj -f exe|dll|cod
```

格式选择优先级（coproj 内配置与 `-f` 命令行，命令行优先）。

---

## 2. `exe`

### 2.1 Native 路径

- PE32/PE32+：`.text` / `.data` / `.idata` 三 section（`PefileWriter`）
- 入口 stub → `main`；导入表（kernel32 的 I/O 函数）
- x86 输出带 `RelocsStripped`（当前可执行文件无重定位，阶段 6 的 dll 需写侧重定位）
- 平台：`--platform x86|x64`

### 2.2 IL 路径

- 托管 PE（自研编码器 + 元数据写入器，阶段 5 完成；互操作走 ImplMap，见 `互操作手册.md` §2.5）
- 调试模式产出 `.pdb`

---

## 3. `dll`

Native 导出库（阶段 6b）。与 exe 的差异：

| 组件 | exe（现状） | dll（新增） |
|------|------------|------------|
| 导出表 `PeExportTable` | 读侧（解析 exe/dll 的导入） | **写侧**（生成导出目录） |
| 重定位表 `PeRelocTable` | 读侧 | **写侧**：基址重定位 |
| 重定位类型 | — | x86: `HIGHLOW`(3)；x64: `DIR64`(10) |
| 符号导出 | — | `export fn` 语法标记 |

### 3.1 `export` 语法

```cocoa
export function Add(a: int, b: int): int { return a + b }
export var version: int = 1
```

- `export` 修饰的函数/变量进入导出表（名称 + RVA）
- 与 `import` 配对：dll 导出 → 消费者 `import foo.dll` → 导入表引用（统一机制）

### 3.2 导出表生成流程

```
1. 收集 export 符号（名称 → 最终 RVA）
2. 生成导出目录（ExportDirectoryTable + 名称表 + 序数表）
3. 重定位扫描：所有指向自身 ImageBase 的绝对地址项
   x86 → HIGHLOW；x64 → DIR64
4. 新增 .edata section 或并入现有 section（定稿时确定）
```

### 3.3 入口要求

- `output = dll` 的项目无需入口函数（可省略 `entry`）
- 若含 `main` 且未 export，不导出

## 4. `cod`

Cocoa 库文件 = IR 序列化（阶段 1 IR 定稿后细化）。

```
COCOD 头（魔数 + 版本 + 平台）
依赖清单（.NET 程序集引用 + native 导入列表，见 项目格式规范.md §4.1）
导出符号表（名称 → IR 符号）
IR 代码区（三地址码序列化：文本或二进制，定稿时确定）
```

- 生成：`-f cod` 时跳过机器码生成，直接输出 IR
- 消费：`[references]` / `-r` 加载 → 反序列化 → 与当前编译单元合并
- 与 dll 的取舍：
  - `cod` = 编译期合并（类似 C++ 头文件/模块单元），无 ABI 风险
  - `dll` = 运行期二进制互操作（C ABI 层），用于跨语言调用

## 5. 依赖关系

| 阶段 | 依赖 | 输出 |
|------|------|------|
| 现 | IR 未定 | 仅 `exe`（Native 可执行文件） |
| 阶段 1 | IR 定稿 | — |
| 阶段 6b | IR + 写侧导出/重定位 | `dll`、`cod` |
