# Cocoa 类库设计

> 状态：设计中（阶段 6e）
> 目标：Cocoa 支持 **class 类库**，编译为 .NET dll，供其他 Cocoa（及 .NET/C#）项目 `-r` + `using` 消费；native 后端对象模型后置。
> 相关文档：`docs/语法手册.md`（§12 类与 OOP、§22 命名空间与导入）、`docs/输出格式.md`、`docs/互操作手册.md`
> 最后更新：2026-08-19

---

## 1. 目标与架构

Cocoa 一门语言，两条后端，均可"发布"：

```
Cocoa 源码（含 public class）
    ├─ -b dotnet ──► .NET dll 类库（-r + using 消费，可被 C#/Cocoa 用）
    │                 .NET exe（netcore `dotnet x.exe` / netfx 直接运行）
    └─ -b native ──► 原生 PE（零依赖，"publish 成 native"）
                      class 对象模型（Rust 所有权语义，后置）
```

### 1.1 输出格式收敛

| 格式 | 输出物 | 消费方式 |
|------|--------|---------|
| `executable`（默认） | exe（Native 或 IL 程序集） | 直接执行 |
| `library` | .NET dll（托管库，无入口） | `-r` 引用 + `using` |

- `cocoa`（.cod 编译期 IR 库）**移除**——.NET dll 承担"库"角色
- `import`：仅 native C dll 互操作（C ABI / P/Invoke），已有
- 跨程序集可见性 = **public 元数据**（无需 `export` 关键字）

### 1.2 里程碑

| 里程碑 | 内容 | 状态 |
|--------|------|------|
| M1 统一修饰符 | public/private + stdcall/cdecl → `Modifiers` 列表 | 待做 |
| M2 class 语言 | `public class Foo` + 字段/方法/构造 + `new`/`this` | 待做 |
| M3 .NET dll 输出 | class → .NET 元数据 + `-f dll`（IL 路径） | 待做 |
| M4 消费 + using | `-r` + Binder 读引用程序集 + namespace/using | 待做 |
| M5 native class | 对象模型 + Rust 所有权 | 后置 |

## 2. 命名约定（对齐 .NET/C#）

| 类别 | 约定 | 示例 |
|------|------|------|
| 类型/类 | PascalCase | `Foo`、`CustomerService` |
| 方法/构造 | PascalCase | `Main`、`GetCustomer`、`Area` |
| 私有字段 | `_camelCase` | `_name`、`_x` |
| 参数/局部 | camelCase | `name`、`count` |
| 常量 | PascalCase | `Count` |
| 命名空间 | PascalCase，点分隔 | `MyApp.Models` |
| 入口 | `Main` | `function Main()` |

- 入口函数固定为 `Main`（`Compilation.Create` 默认），不再接受小写 `main`
- 现有函数名迁移为 PascalCase（`add`→`Add`）
- 关键字一律小写（`function`/`class`/`import`/`public` 等）

## 3. 统一修饰符系统

### 3.1 语法

```
<modifier>* <声明关键字> <...>
modifier := public | private | stdcall | cdecl
```

- 修饰符顺序无关、可组合（未来扩展 `static`/`abstract`/`sealed`/`virtual`/`override`/`readonly`，见语法手册 §12.2）
- 每个声明节点携带 `ImmutableArray<SyntaxToken> Modifiers`（挂在 `MemberSyntax` 层）
- 无 `export` 关键字（跨程序集可见性由 `public` 承担）

### 3.2 合法性与语义

| 修饰符 | 类 | 方法 | 字段 | 语义 |
|--------|:--:|:----:|:----:|------|
| `public` | ✅ | ✅ | ✅ | 跨程序集/类外可见 |
| `private` | ❌ | ✅ | ✅ | 仅本类可访问 |
| `stdcall`/`cdecl` | ❌ | ✅ | ❌ | 调用约定（P/Invoke / C ABI） |

- 绑定层按声明类型校验修饰符合法性（如 `private` 仅类成员）

### 3.3 后端映射

| 可见性 | IL 后端 | native 后端 |
|--------|---------|-------------|
| `public` 类/方法/字段 | 元数据 public（可被外部引用） | 对象模型（后置） |
| `private` 成员 | 元数据 private | 对象模型（后置） |

## 4. class 语言（语法手册 §12 细化）

### 4.1 语法草案

```cocoa
public class Point
{
    private _x: int
    private _y: int

    public constructor(x: int, y: int)
    {
        _x = x
        _y = y
    }

    public function Distance(): double
    {
        return ...
    }
}
```

### 4.2 语义

- **字段**：类型化成员，`private`/`public`
- **方法**：带 `this`（实例）语义；`public function` / `private function`
- **构造**：`public constructor(...)`，`new Foo(...)` 调用
- **实例访问**：`foo.Method()`、`foo.Field`
- **对象语义**（IL 后端）：引用类型（CLR 托管对象，GC）
- **native 后端**：Rust 所有权语义（见 §8，后置）

### 4.3 IL 元数据

- `public class Foo` → TypeDef `public`（0x1）
- `public function` → MethodDef `public static` / 实例方法
- 字段 → FieldDef 可见性
- 构造 → MethodDef `.ctor`

## 5. 命名空间与 using（语法手册 §22 细化）

### 5.1 声明

```cocoa
namespace MyLib
{
    public class Foo { ... }
}
```

- 命名空间必须 `{}` 包裹成员
- IL 类名 = `Namespace.ClassName`

### 5.2 导入

```cocoa
using MyLib
using System

let f = Foo()          // 非限定名（using 提供前缀）
System.Console.WriteLine("hi")   // 完全限定名（无需 using）
```

- 名称解析：直接全名 → using 前缀拼接 → 报错
- `using` 仅编译期影响名称解析（文件级指令；与 §10.14 资源管理 using 语句区分）

---

## 6. .NET dll 输出（M3）

- `-f dll` / `output = library`（IL 路径）接通，产出托管库（无入口）
- 元数据：public 类/成员正确标记（供外部引用）
- netcore / netfx 库均可（`--dotnet-runtime` 生效）
- 与 exe 差异：无入口点、无 runtimeconfig（库不直接运行）

---

## 7. 跨程序集消费（M4）

- 消费方 `-r mylib.dll`（或 `[references]`）
- Binder 读引用程序集元数据（`MetadataReader` 已有）：
  - public 类型 → Cocoa 侧"外部类型符号"（含成员表）
  - public 方法/字段 → MemberRef
- `using` 前缀 → 类型解析
- 消费方 `new Foo()` / `foo.Method()` 绑定 + 发射（MemberRef 已有基础）

### 7.1 类型系统扩展

- `TypeSymbol` 增加"类类型"（成员表：方法/字段/构造 + 可见性 + 归属程序集）
- 内建类型（int/string 等）与 .NET 类型映射（int→Int32、string→String）复用现有 Emitter 映射

---

## 8. native 后端（后置，概要）

- 对象内存布局（字段对齐/偏移）
- 实例方法（this 参数）、堆分配（复用 VirtualAlloc 分配器）
- **Rust 所有权语义**：所有权移动、借用（不可变/可变）、作用域 drop、借用检查器（静态分析）
- 详细设计在 M5 单独细化

---

## 9. 内置函数演进（后置）

当前内置：`print`/`input`/`random`（编译器硬编码）。

- 演进为**标准库**（与类库同构）：per-backend 符号
  - IL：`print` → `System.Console.WriteLine` 包装
  - native：`print` → `WriteConsoleW` 自研运行时
- 命名：PascalCase（`Print`/`Input`/`Random`），或保留小写作为语言级标准函数（待定）
- 引入方式：隐式注入或显式 `using`（待定）
- 本次保留内置，不迁移

---

## 10. 明确的取舍

- **不做**（本次）：native class / Rust 所有权、`.cod` 库、`export` 关键字、内置→标准库迁移
- **后置**：native 对象模型、标准库、完整 OOP（继承/多态/属性/static，语法手册 §12 全套）
- 类库闭环（M1-M4）为本次范围，验证"写类库 → 编译 dll → using 消费"
