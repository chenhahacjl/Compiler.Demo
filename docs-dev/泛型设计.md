# Cocoa 泛型设计 — 编译期单态化（模板式特化）

> 状态：🔧 设计中（2026-08-22，6e-M20 规划）
> 目标：为 Cocoa 引入**泛型类 / 泛型接口 / 泛型方法 / 约束**，解锁泛型集合（`List<T>`）与枚举器模式 foreach——这是 `docs/OOP设计.md` §13.3 明确的最大结构性缺口。
> 核心模型：**编译期单态化（monomorphization，模板式特化）**——泛型定义是"模板"，每个唯一类型实参元组在编译期展开为独立的具体类型。非 .NET 运行时泛型。
> 相关文档：`docs/对象模型设计.md`（System.Object/native vtable）、`docs/OOP设计.md`（§13.2/§13.3）、`docs/标准库设计.md`、`docs/互操作手册.md`（§229 已注明"编译期特化"）

## 1. 目标与范围

- **泛型类** `class Box<T>`、**泛型接口** `interface IEnumerable<T>`、**泛型方法** `function Swap<T>(...)`、**约束** `where T: IComparable<T>`。
- 实例化 `new List<int>()`、`List<string>`、`Swap<int>(a, b)`、数组/嵌套 `List<List<int>>`。
- 首批 stdlib：`System.Collections.Generic.List<T>`（动态数组）+ `IEnumerable<T>`/`IEnumerator<T>` 接口。
- 目标后端：**Evaluator / IL / native x86/x64** 四路一致。
- **范围外**（本里程碑）：`Dictionary<K,V>`、LINQ、`struct` 泛型、协变/逆变（`in`/`out`）、运行时泛型反射、`.coa` 跨程序集泛型实例化（见 §12）。

## 2. 核心模型：编译期单态化

### 2.1 为什么不是 .NET 运行时泛型

| 维度 | 运行时泛型（.NET） | 编译期单态化（本设计） |
|------|--------------------|------------------------|
| 元数据 | GenericParam / GenericInstanceType / callgeneric | **无新元数据**（发射侧零改动） |
| 实例化 | 运行时 JIT 按类型实参实例化 | 编译期按类型实参展开成独立类型 |
| native | 需要运行时泛型类型系统（极难） | 每个实例化 = 独立 vtable/typeId/字段布局，**天然复用对象模型** |
| `.coa` | 需序列化泛型实例化图 | 序列化泛型定义，消费方编译期实例化 |
| 代码体积 | 共享方法体 | 每实参元组一份（可接受，本语言无极端组合场景） |
| 静态性 | 类型检查在声明期 | 约束在实例化期校验（类似 C++ 模板，但用 C# 式 where 约束显式化） |

### 2.2 模型定义

```
List<T>   （泛型定义，模板）
  ├── 实例化 List<int>    → 独立具体类 List_Int32
  └── 实例化 List<string> → 独立具体类 List_String
```

- 每个实例化类：字段类型替换、方法签名替换、方法体 `T → 实参` 替换后重新绑定。
- 实例化**按唯一实参元组去重**（`List<int>` 全编译共享同一实例化）。
- 泛型方法与泛型类正交：泛型方法在具体类内展开为具体方法。

## 3. 语法

### 3.1 泛型类

```cocoa
public class List<T>
{
    private _items: T[]

    public constructor() { _items = new T[0] }

    public function Add(item: T): void { ... }
    public function Get(index: int): T { return _items[index] }
    public function Count(): int { return _items.Length }
}
```

### 3.2 泛型接口

```cocoa
public interface IEnumerable<T>
{
    function GetEnumerator(): IEnumerator<T>
}

public interface IEnumerator<T>
{
    function MoveNext(): bool
    function get_Current(): T        // 属性 Current（C# 风格）或 property Current: T
}
```

### 3.3 泛型方法

```cocoa
function Swap<T>(a: T, b: T): void { ... }              // 顶层泛型方法

public static class ArrayUtils
{
    public static function Swap<T>(a: T[], i: int, j: int): void { ... }
}
```

### 3.4 实例化（类型实参）

```cocoa
var list = new List<int>()
list.Add(1)
var names = new List<string>()
names.Add("a")

var grid = new List<List<int>>()     // 嵌套
Swap<int>(a, b)                      // 泛型方法显式类型实参（可推导时省略）
```

### 3.5 约束（where）

```cocoa
public class SortedList<T> where T: IComparable<T> { ... }   // 接口约束
public class Store<T> where T: Base { ... }                   // 基类约束
public class Factory<T> where T: new() { ... }                // 无参构造约束
public class Ref<T> where T: class { ... }                    // 引用类型约束
public class Val<T> where T: struct { ... }                   // 值类型约束（后续）
```

## 4. 类型系统

### 4.1 新增符号

- `TypeParameterSymbol : TypeSymbol`——`name`、`ordinal`、`Constraints`（约束类型列表 + 标志 `new()`/`class`/`struct`）。泛型上下文内为"不透明类型"。
- `ClassTypeSymbol` 增 `TypeParameters: ImmutableArray<TypeParameterSymbol>`（空 = 非泛型）与 `IsGenericDefinition`。
- `InstantiatedTypeSymbol : ClassTypeSymbol`——`GenericDefinition`（泛型定义类）+ `TypeArguments: ImmutableArray<TypeSymbol>`。实参可为具体类型或（嵌套泛型上下文内）外层 `TypeParameterSymbol`。

### 4.2 类型替换 Substitute

`Substitute(TypeSymbol t, ImmutableDictionary<TypeParameterSymbol, TypeSymbol> map)`：

- `TypeParameterSymbol` → `map[t]`（无映射则保留 = 仍为泛型上下文）。
- 数组类型 → 递归替换元素类型。
- `InstantiatedTypeSymbol` → 递归替换实参后重新实例化（去重）。

### 4.3 LookupType 泛型解析

- `LookupType("List")` → 泛型定义类。
- `LookupType("List<int>")`（TypeClause 增类型实参解析）→ 绑定实参 → `Instantiate(definition, args)`（缓存去重）。
- 与数组 `T[]` 的 `TypeSymbol.ArrayOf` 去重模式同构。

### 4.4 命名 mangle（IL/native 唯一名）

实例化类名 = `定义名 + "_" + 实参编码`（实参名转义 `[]`/泛型 `<>`/点号，参照 IL `EncodeTypeNameForMethodName`）：`List<int>` → `List_Int32`，`List<string>` → `List_String`，`List<List<int>>` → `List_List_Int32`。

## 5. 约束（where 子句）

### 5.1 约束形式

| 形式 | 语义 | 开放能力 |
|------|------|---------|
| `where T: IInterface` | 实现接口（可多个） | `t.InterfaceMethod()`、隐式转接口 |
| `where T: BaseClass` | 继承基类（至多一个非接口） | 访问基类成员、隐式转基类 |
| `where T: new()` | 有无参公共构造 | `new T()` |
| `where T: class` | 引用类型 | 可 `null`（后续可空语义）、引用相等 |
| `where T: struct` | 值类型（后续） | 值语义 |

### 5.2 语义规则

- 声明期：对 `T` 的成员访问仅限约束开放（无约束 → 只能存储/返回/传递，不能调成员）。
- 实例化期：实参满足全部约束（`int` 满足无约束/`struct`；`string` 满足 `class`；`ComparableImpl` 满足 `IComparable<T>` 等），不满足 → 诊断 `ReportConstraintViolation`。
- 类型实参可为另一个类型参数：`class Foo<T, U> where T: IComparable<U>`。

## 6. 绑定：定义期与实例化期

### 6.1 定义期（泛型上下文）

- `DeclareClassGroup` 识别类型参数 + 约束，建 `TypeParameterSymbol` 入作用域。
- 成员绑定用 `TypeParameterSymbol` 作类型：字段 `_value: T`、方法 `Get(): T`、构造 `(value: T)`。
- 方法体绑定：`T` 不透明；`t.ConstraintMethod()` 解析到约束接口/基类成员；`new T()` 需 `where T: new()`。
- **诊断**：约束外调用 `T` 成员 → `ReportTypeParameterMemberNotAllowed`；缺 `new()` 用 `new T()` → 报错。

### 6.2 实例化期

- `BindTypeClause("List<int>")`：实参 `int` → `Instantiate(List, [int])` → 校验约束。
- 实例化类成员 = 定义类成员经 `Substitute`（字段/方法签名/属性/构造签名）。
- 方法体重新绑定：以替换后的 `InstantiatedClassTypeSymbol` 为容器，Binder 复用对普通类绑定（T 已全部替换为具体类型）。
- 实例化类的基类/接口同样实参化（`List<T>` 若继承 `Collection<T>` → `List<int>` 继承 `Collection<int>`）。

## 7. 单态化展开算法

1. **实例化缓存**：`Instantiate(definition, typeArgs)` → 全局去重字典（按 `(definition, typeArgs)` 引用相等键）。
2. **可达性收集**：从入口沿 `new List<int>()`、`List<int>` 类型标注、泛型方法调用、实例化类的成员调用收集**活实例化**（仿 native 可达性过滤；stdlib 未用泛型不展开）。
3. **展开**：对每个活实例化——建 `InstantiatedTypeSymbol`，成员签名 `Substitute`，方法体重新绑定，字段类型替换。
4. **递归**：展开过程中产生新实例化（`List<int>` 的字段 `T[]`→`int[]`；方法体 `new List<int>()` 已并入收集）。
5. **出口**：展开完成后，`program.Classes` 含全部实例化类（作为普通类），三后端按现有管道发射。

## 8. 泛型方法

- 泛型方法签名含 `TypeParameters`；`ResolveMemberOverload`/`BindCallExpression` 增类型实参解析。
- 调用 `Swap<int>(a, b)`：显式实参绑定 T=int；`Swap(a, b)`：类型推导（`a:T, b:T` 从实参推导，可选首版只做显式）。
- 展开：`FunctionSymbol` 增加 `Instantiate(genericMethod, typeArgs)` → 具体方法（类型替换后重新绑定体），命名 mangle `Swap_Int32`。
- 在实例化类内展开时，方法类型参数与外层类类型参数可混合（`class Box<T> { function Map<U>(f: U): T }`）。

## 9. IL 发射

- **不发射 GenericParam/GenericInstanceType**（模板模型）：实例化类 → 独立 TypeDef（mangle 名），字段/方法类型全为具体类型。
- 实例化类的基类/接口 → 具体 TypeRef/TypeDef（`Extends`/`InterfaceImpl` 实参化）。
- 泛型方法 → 具体 MethodDef；`call` 直接引用。
- `MetadataReader` 写侧不动（读侧已支持 GenericParam 解码，供 .NET 泛型类型引用，见 §15 边界）。
- 依赖：实例化类 = 普通类 → 复用现有 IL class 发射（含 `对象模型设计.md` M3 的 Object 方法）。

---

## 10. native 发射

- 实例化类 = 独立类 → 复用 `对象模型设计.md` §8 对象模型：独立 vtable/typeId/字段偏移/实例方法 `this`。
- `List<int>` 与 `List<string>` 不同 typeId、不同 vtable、`GetType()` 返回各自 Type。
- 泛型方法 = 普通函数（类型已替换），无额外机制。
- **依赖**：native 用户类对象模型（对象模型设计 M4）须先落地。

---

## 11. Evaluator

- 实例化类 = 具体类：Evaluator 以 C# 类实例承载（如 `Box<int>` → 内部 `Box_Int32` CLR 对象，字段/方法按具体类型求值）。
- 泛型方法 = 具体函数调用。
- 无运行时泛型，Evaluator 无需 `typeof(T)`/反射。

## 13. stdlib：List<T> 与枚举器接口

### 13.1 `System.Collections.Generic.List<T>`（动态数组）

```
namespace System.Collections.Generic
{
    public class List<T>
    {
        private _items: T[]
        private _count: int

        public constructor()
        public constructor(capacity: int)

        public function Add(item: T): void        // 扩容 ×2
        public function Get(index: int): T         // 越界检查
        public function Set(index: int, value: T): void
        public function Count(): int               // 或属性 Count
        public function Clear(): void
        public function Contains(item: T): bool    // 需 Equals（Object 模型后）
        public function IndexOf(item: T): int
        public function RemoveAt(index: int): void
        public function ToArray(): T[]
    }
}
```

> 依赖：`T[]` 扩容 = `new T[n]` + 循环拷贝（语言可表达，无需 GC 特例）。

### 13.2 枚举器接口（foreach 升级铺路）

- `IEnumerable<T>` / `IEnumerator<T>`（§3.2）。
- `foreach (var x in list)` 降级改为调用 `GetEnumerator()/MoveNext()/Current`（`docs/开发计划.md` §6f P6 策略点）。

## 14. 与现有特性联动

| 特性 | 联动 |
|------|------|
| Object 基类（对象模型） | 泛型类的 `BaseType` 实参化；实例化类继承 Object；约束 `where T: class` 关联引用语义 |
| `==`/`!=` 引用相等 | `List<int>` 引用相等；元素比较走元素类型 `Equals` |
| foreach 策略点 | 升级枚举器模式（G6） |
| 运算符 | 泛型 `Max<T>` 需 `where T: IComparable<T>`（比较接口），`a > b` 运算符不作用于泛型 T |
| 静态容器类重载 | 泛型方法独立于重载（同参数签名 + 不同类型参数数视为不同） |
| `.coa` 库 | 泛型定义随库携带，消费方单态化 |

## 15. 语言能力边界

| 不做 | 原因 |
|------|------|
| 运行时泛型反射（`typeof(T)` 值、`List<T>.Type`） | 单态化无运行时泛型 |
| 协变/逆变 `in`/`out` | 需要运行时泛型类型系统 |
| LINQ（`IEnumerable<T>` 扩展方法链） | 扩展方法未实现；泛型落地后可作为后续 |
| `.NET 泛型类型引用`（`List<T>` ↔ mscorlib `List<T>`） | 语义层与 .NET 运行时泛型是两套体系（互操作手册 §229） |
| `where T: unmanaged` / `default(T)` / `where T: notnull` | 无 unmanaged/nullable 体系 |
| `struct` 泛型值语义 | struct 未实现 |

## 17. 验收标准

- `new List<int>()`/`new List<string>()`/`new List<List<int>>()` 四路一致（Add/Get/Count/Contains/ToArray）。
- 泛型方法：显式 `Swap<int>(...)` + 类型推导（若做）四路一致。
- 约束：`where T: IComparable<T>`/`where T: Base`/`where T: new()` 开放成员 + 实例化期违约束诊断。
- 泛型类继承/接口实参化（`class MyList<T>: List<T>`）。
- native：`List<int>` 与 `List<string>` 独立 vtable/typeId，`GetType()` 各自 Type。
- foreach 枚举器模式：`foreach (var x in list)` 走 `GetEnumerator/MoveNext/Current`。
- 全量测试回归通过；文档（`OOP设计.md`/`标准库设计.md`/`语法手册.md`/`开发计划.md`/`互操作手册.md`）同步。
