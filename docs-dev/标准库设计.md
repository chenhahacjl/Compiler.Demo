# 标准库设计（System.Core 分层与约定）

> 状态：生效 2026-09-06（Syscall 收口 · 单库布局）
> 对应实现：`src/Cocoa.SDK/System.Core/`

## 1. 模块与目录

标准库收敛为**单个** `System.Core` 库（对齐 .NET `System.Private.CoreLib` 单项目形态）。
`System.Core.coproj` 按目录 glob 收集源码：

```
src/Cocoa.SDK/System.Core/
  *.co             namespace System 的基元/封装（Array/Int32/String/Console/…）
  IO/*.co          namespace System.IO（Stream 家族 + Path/File/FileStream）
  Collections/*.co namespace System.Collections.Generic
  Syscall/*.co     namespace System.Syscall —— 全部 syscall 声明（底座收口）
```

`Cocoa.SDK.cosln` 仅含 System.Core 一个工程；`System.IO`/`System.Collections` 独立工程已移除。

## 2. Syscall 收口约定

- 所有系统级 `syscall function ...` 声明**只**放在 `Syscall/` 目录、`System.Syscall` 命名空间，文件按域拆：
  `FileSyscall`（文件级用户 API 底座）、`IOSyscall`（句柄原语）、`StringSyscall`、
  `ConsoleSyscall`、`MathSyscall`、`ProcessSyscall`、`EnvironmentSyscall`。
- **方法名保持原名**（`FileOpen`/`StringFromBytes`/`WriteLine`…）：BuiltinKind、IL/native/Evaluator
  三发射器与 `BuiltinFunctions.cs` 全部按方法名分发，容器迁移不破坏它们。
- `Runtime`（`System.Runtime` class）只保留**带体**工具（数值/文本格式化 `Floor`、`Int*/UInt*ToString` 等），
  不再承载 syscall；syscall 在 `Runtime` 内的历史调用点已迁移到对应 `Syscall` 类。

## 3. facade 原则（BCL 存在类型即 facade）

- 凡是 .NET/BCL 已有对应类型的 SDK 类型，一律标 `facade`：
  IL 侧直链 BCL 同名成员；native/Evaluator 走库内体（或体→Syscall）。
- 双方言 Binder 的 `FacadeTargets` 表（`CocoaBinder.TypeResolution.cs` / `CSharpBinder.TypeResolution.cs`）
  必须**同步维护**（差异化即 SyntaxDuplicationDrift 失败）。
- 已 facade：`System.IO.Path`、`System.IO.File`（体转发 `FileSyscall`）、`System.IO.FileStream`、`System.Math`。
- 常规于编译期判定：facade 成员在 IL 侧 `_framework.FindMethod` 未命中时应**回退走体发射**或**桩**，
  不许硬抛（否则形如 `AppContext not found in framework references` 的整批回归）。

## 4. 已知例外（真实体，不上 facade）

- `System.Console` / `System.Environment`：真实类 + body → `ConsoleSyscall` / `EnvironmentSyscall` 转发
  （IL 侧为 `System.Console` 提供 BCL 快捷引用并 Box 值类型参数；`Environment.GetExecutablePath`
  无 BCL 对应，走 NotSupported 桩兜底）。已在本文记录，勿误改回纯 `class`。
- `System.Convert`：条件特性（非法 hex/base64 输入返回空数组，不与 BCL 抛异常语义一致，
  `.co` 序列化尚不支持 `throw` 语句），保持真实体；`FacadeTargets` 无此条目。

## 5. 命名与迁移纪律

- 文件移入子目录后须触碰 mtime 触发重建（build-sdk）。
- 用户侧可见 API（`System.Console.WriteLine`、`System.IO.File.*`）不得随收口改变签名。
- 新增 syscall：在 `Syscall/<域>Syscall.co` 声明 + `BuiltinFunctions/Specs`/发射器补绑定；
  若为 BCL 对应类型成员，先评估 facade 直链是否可用。
