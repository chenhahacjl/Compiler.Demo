## 0. 动机与决策转变

**现状（2026-08-24 C5++ 定案）**：结构化函数类型 fnty `(A,B)->R` 为内核，delegate 声明 = 纯语法糖——编译期 `NamedTypeSymbol{TypeKind.Delegate, BaseType=MulticastDelegate}` + `Invoke` 签名载体，运行期擦除为 Func/Action；多播归事件侧数组字段 `_<e>` + 语句级脱糖；`==`/`-=` 引用相等；无泛型 delegate；`<in/out T>` 型变注解报「泛型无运行时型变」诊断。

**决策转变**：对齐 C# 立场——delegate 是**运行期真实类型**（对象 + 多播机制），类型声明不降级。驱动点：`.coa` 已完成 .NET dll 等价化（阶段 6 收尾），delegate 作为类型应跨越编译期/运行期双界；native 已有 M4 类型系统（对象头 vtable = Type 对象、GetType/is/as 先行），等价真类型可同步达成。

## 1. 目标规格（C# 式）

| # | 项 | 目标 |
|---|---|---|
| 1 | 类型身份 | `delegate TResult Handler<in T, out TResult>(T)` 是真类型：IL 侧 `typeof`/反射/`GetType().Name`，native 侧对象头 vtable = Handler 的 Type（名串 "Handler"），Evaluator 托管对象 |
| 2 | 运行期表示 | IL = 真 `MulticastDelegate` 子类（`.ctor(object, native int)` + `Invoke`，不发射 BeginInvoke/EndInvoke——.NET Core 委托只需 ctor+Invoke）；native = 普通存活类 + 内部 `list: Fn[]`（函数指针+env 配对数组，元素复用现成 3 字函数值）；Evaluator = 托管列表 |
| 3 | 多播 | `+`/`-` = Delegate.Combine/Remove（调用列表、子序列匹配移除）；调用快照遍历；非 void 返回最后目标结果 |
| 4 | 相等 | `==`/`!=` = Delegate.Equals（调用列表逐元素比对） |
| 5 | 事件 | 迁 C# 式 add/remove——后备字段类型 = 委托类，`_e = Combine(_e, v)`/`Remove`，触发 = 判空 + 快照 `_e(...)`；删 `_<e>` 数组字段 + 语句级数组脱糖 |
| 6 | 泛型 + 型变 | 支持 `delegate D<T>` 与 `<in T>`/`<out T>`/`<in out T>`；型变安全位诊断（CS1961/1962 对齐）；赋值兼容 = 参数逆变 + 返回协变 |
| 7 | fnty 内核 | 未具名 `(A,B)->R` 位置保持 Func/Action 映射（不变）；fnty↔fnty 结构相等不变型；型变仅在具名 delegate 赋值方向生效且为 reference-preserving 纯类型变换 |

## 2. 决策记录（Q1-Q4 已拍板）

| 决策点 | 结论 |
|---|---|
| Q1 后端覆盖 | **A**：IL 真 CLR 委托（MulticastDelegate 子类）；native 等价真类型对象（vtable + 函数指针数组）；Evaluator 托管列表对象——三后端类型身份存续、语义锁定 |
| Q2 事件多播 | **A**：事件迁 C# 式 add/remove，后备字段 = 委托类，调用列表组合；删数组脱糖 |
| Q3 相等/移除 | **A**：`==`/`!=`/`+=`/`-=` 全面升调用列表语义（Delegate.Equals/Combine/Remove） |
| Q4 泛型 | **B**：支持泛型 delegate + 引入 in/out 型变（含安全位诊断与赋值兼容）；函数类型本身不变型 |

## 4. 关键边界

- **型变范围锁定为 delegate 声明**；接口 `in/out` 型变 = 后续项，符号模型按通用设计不封死
- fnty↔fnty 不变型；型变仅「具名 delegate 实例化 → 目标」方向生效且为 reference-preserving（native 零成本纯类型变换）
- BeginInvoke/EndInvoke 不发射（.NET Core 委托类型只需 ctor+Invoke）
- 泛型 delegate 的 `.coa` open-typed Invoke 复用既有 tps/fnty/fnval 管线，Substituter 全节点替换覆盖
- 事件后备字段为内部存储（native 特有 list 字段不序列化，与 `_<e>` 同级内部形态）
