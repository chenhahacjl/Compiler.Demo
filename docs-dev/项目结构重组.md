## 5. Cocoa.Targeting 类型模型

```
Cocoa.Targeting/                        第 0 层，零依赖
├── TargetPlatform.cs                   ← 迁自 PE：TargetOS（Windows/Linux/MacOS）、
│                                         Architecture（X64/X86/Any★预留）、
│                                         TargetPlatform record（TryParse/ToString）、
│                                         CodeBackend（DotNet/Native，统一取代 ProjectBackend）
└── IlTarget.cs                         ← 迁自 Core\Emit\：IlRuntime（NetFx/NetCore）、
                                          IlTarget（net40~net48、net8.0+；将来 net10 只加解析分支）
```

明确不进 Targeting：OutputFormat（Exe/Dll/Cod → Build 层组合判断）、Debug/Release（构建配置）、CallingConvention/CharSet（函数级签名属性 → Core.Symbols）。

## 6. 依赖链（单向无环，零 InternalsVisibleTo）

```
第 0 层  Cocoa.Targeting(0)   Managed.Structure(0)   Native.Lir(0)
         PE → Targeting
第 1 层  Managed.Reader → Structure
第 2 层  Compiler.Core → Reader + Targeting
第 3 层  Managed.Writer → Structure + Reader + Core
         Native → Native.Lir + Core + Targeting
         Dialects.Cocoa / Dialects.CSharp / Interpreter → Core
第 4 层  Cocoa.Build → Core + Writer + Targeting     （对 PE、Native 的引用删除）
第 5 层  Cli → 全部    Cli.Repl → 方言 + Core    Tests → 全部
```

关键消解：
- **Core→PE 断开**：`TargetPlatform` 迁 Targeting，PE 的 `PeFileWriter` 改引 Targeting（方向向下，合法）
- **Managed.Writer 循环消解**：Reader 下沉后 Core 只引用 Reader，Writer 引用 Core 单向
- **Cocoa.Build 瘦身**：`ParseTargetPlatform` 直接产出 `Targeting.Architecture`，`EmitNative(platform)` 强类型传递

### 7.3 InternalsVisibleTo 清零策略

- 删除全部 csproj 的 `<InternalsVisibleTo>`；**编译错误驱动**（TreatWarningsAsErrors 已开启）：每个跨程序集访问点由 CS0122/CS0051 精确定位，`internal` → `public`
- 预计规模：Core ~40+ 类型（BoundProgram/BoundScope/DiagnosticBag/BuiltinFunctions/Lowerer/CoaSerializer 等）、PE ~15+ 类型
- 仅单程序集内使用的 internal 保持不变；不引入反射；Tests 访问的内部类型同样转 public

### 7.4 文件编码与换行符规则（迁移全程强制）

**编码：**

1. 全库统一 UTF-8（无 BOM，与 `.editorconfig` `charset=utf-8` 一致）；禁止新增 GBK/GB2312 编码文件
2. 迁移/编辑中若发现乱码注释：按 A10 批次模式**手工重写**对应行，禁止整文件脚本转码
   （历史教训：转码误判曾引入二次乱码，见提交 820918d）
3. 新建文件一律 UTF-8 + CRLF

**换行符：**

4. 工作区统一 CRLF；`*.sh`、`.git*` 文件保持 LF（`.editorconfig`/`.gitattributes` 既有约定，不复议）
5. 入库归一化由 `.gitattributes`（`* text=auto eol=crlf`）完成——**迁移必须用 `git mv` 保留历史**，
   避免整文件重写触发全文件重归一，造成 diff 噪音淹没真实改动
6. 禁止提交混合换行文件；编辑后如产生混合 EOL，提交前统一为该文件类型的约定换行

**尾随空白与文件末尾：**

7. `trim_trailing_whitespace=true`：不引入行尾空白
8. 普通文件无末尾换行；`.sh`/`.git*`/脚本类保持有（既有 editorconfig 约定）

**二进制保护：**

9. ★ 已随本文修复缺口：`.gitattributes` 补 `*.coa binary`（libs/ 下 2 个预编译库此前未受保护，
   本轮迁移触碰 libs/ 时有被换行归一化损坏的风险）；同时补 `*.stamp`、`*.cache` binary

**验证：**

10. 每步执行后抽查：`git ls-files --eol` 无 mixed 换行；迁移 diff 中不得出现
    "整文件每行变更"（那是重归一化事故的标志）
