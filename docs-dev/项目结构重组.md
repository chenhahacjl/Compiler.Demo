## 2. 目标结构

### 2.1 程序集族（对称双族）

| 族 | 程序集 | AssemblyName | 类型 | 现名 → 目标名 |
|---|---|---|---|---|
| **库族**（不动，A3-4 刚定稿） | `Cocoa.Core` | Cocoa.Core | Library | — |
| | `Cocoa.Core.Cocoa` | 同名 | Library | — |
| | `Cocoa.Core.CSharp` | 同名 | Library | — |
| **可执行族** | `Cocoa.Compiler` | `cocoa` | Exe | —（主 CLI 不动） |
| | `Cocoa.Compiler.Cocoa` | `coc` | Exe | **← `Cocoa.CoCompiler`** |
| | `Cocoa.Compiler.CSharp` | `csc` | Exe | **← `Cocoa.CsCompiler`** |
| 支撑 | `Cocoa.Generators`（源生成器） | 同名 | Library(netstd2.0) | — |
| | `Cocoa.Tests` | 同名 | Test | — |

- **AssemblyName 全部不变**：`cocoa`/`coc`/`csc` 是用户面命令名（蓝图 §6.1 命名体系），`InternalsVisibleTo` 按程序集名授予，零影响。
- `csc` 与 .NET 自带编译器重名是蓝图 §6.1 的既定取舍，本文不复议（PATH 场景注意即可）。
- 命名空间同步：两改名项目的 `Program.cs` 命名空间 `Cocoa.CoCompiler`/`Cocoa.CsCompiler` → `Cocoa.Compiler.Cocoa`/`Cocoa.Compiler.CSharp`，csproj 的 RootNamespace 同步。

### 2.2 `src/Cocoa.Cs` 分组目录

```
src/Cocoa.Cs/
├── Cocoa.sln / Cocoa.slnx / Directory.Build.props / Directory.Build.targets
├── build.cmd/.sh · cocoa.cmd/.sh · libs/System.Core.coa   （留根）
├── Compilers/                     # 3 个 Exe
│   ├── Cocoa.Compiler/
│   ├── Cocoa.Compiler.Cocoa/      # ← Cocoa.CoCompiler/
│   └── Cocoa.Compiler.CSharp/     # ← Cocoa.CsCompiler/
├── Core/                          # 4 个 Library
│   ├── Cocoa.Core/
│   ├── Cocoa.Core.Cocoa/
│   ├── Cocoa.Core.CSharp/
│   └── Cocoa.Generators/
└── Tests/
    └── Cocoa.Tests/
```

src 顶层占位语义保留不动：`Cocoa.Co/`（阶段 7 自举）、`Cocoa.IDE/`（Avalonia 路线）、`Cocoa.SDK/`（CO 源码标准库）。

### 2.3 CodeAnalysis 根整形（18 → 8 文件 + 两族归位）

```
CodeAnalysis/
├── Compilation.cs / Language.cs / SemanticModel.cs           # 门面
├── CocoaCompilation.cs / CSharpCompilation.cs                # 方言子类（暂留根，随 A3/B2 迁方言舱）
├── MetadataReference.cs / SystemLibrary.cs / ByRefBox.cs     # 跨切基元
├── Diagnostics/    ← Diagnostic.cs · DiagnosticBag.cs · DiagnosticExtensions.cs
├── Evaluation/     ← Evaluator.cs · Evaluator.{Calls,Expressions,Members,Statements}.cs
│                     · EvaluatorRuntime.cs · EvaluationResult.cs
└── Binding/ Cod/ Emit/ Lowering/ Symbols/ Syntax/ Text/      # 既有子目录不动
```

**命名空间一律不变**（`Cocoa.CodeAnalysis` / `Cocoa.CodeAnalysis.Diagnostics` 等——目录即命名空间的假设在此不成立，本项目以程序集为单位组织命名空间）；纯 git mv。

### 2.5 其他归位

- `Syntax/Green/RedNode.cs` → `Syntax/RedNode.cs`（红节点出 Green 目录）。
- `Emit/Native/Runtime/Windows/{X64,X86}/Runtime.X{64,86}.cs` → `Emit/Native/Runtime/`（上提一层；**namespace 从 `…Runtime.Windows.X64/X86` 合并为 `…Runtime`**，grep 全限定引用同步——本轮唯一 namespace 变更点）。
- 删空目录 `Emit/IR/`（未跟踪垃圾）。

### 2.6 仓库卫生

git 跟踪面已干净（产物零跟踪），卫生项全部为**本地未跟踪垃圾清理**：`.vs/`（src 根与 Cocoa.Cs 下）、`Emit/IR/` 空目录、obj 内 `Cocoa.CocCompiler.*` 旧名残留（改名项目重建时自然消失）。`.gitignore` 无需增补（`/.zcode` 已加，随本轮提交）。
