## 1. 双轨定义

| | C# 轨（参考实现） | .co 轨（自举实现） |
|---|---|---|
| 位置 | `src/Cocoa.Cs`（13 工程，~600 `.cs`） | `src/Cocoa.Co`（编译器 62 `.co` ~620KB）+ `src/Cocoa.SDK`（58 `.co`） |
| 角色 | 语言语义权威、IDE 宿主、三后端齐全 | 目标：编译自己能编译自己（B1≡B2 fixpoint） |

### 已知限制（源码注释自陈）

- 实参仅基础字面量 `string/i32/f64/bool/char`（`BindAttributeLiteral`）；不支持 `new` 表达式、数组、命名实参

- 未知 ctor / 参数类型不匹配**静默不报错**
- 名称归一：`[X]` → 试 `X` 再试 `XAttribute`

### 唯一有语义的属性

`[Facade("System.IO.File")]` —— 把类标记为 BCL facade，映射到真实 .NET 类型。消费点：
- `CocoaBinder.TypeResolution.cs:586-611`（`TryGetFacadeAttribute`）
- `CocoaBinder.cs:261`
- `SyntaxNode.cs:304`（`cls.Attributes.Any(a => a.Name.Text == "Facade")`）

## 6. 重点专题：运算符重载

### 现状：未实现

| 证据 | 说明 |
|---|---|
| `SyntaxKind`（C# 199 kind / .co 全量） | **无 `operator` / `Implicit` / `Explicit` / `Conversion` kind** |
| `BoundBinaryOperatorKind` | 固定枚举（`Addition` / `Greater` / …），三后端各自 `switch` |
| 全仓 grep `op_Addition` / `op_Implicit` | C# 轨 0 命中（仅 `BoundBinaryOperatorKind` 等无关符号） |
| `.co` 侧 `BoundBinaryOperator.co` | 仅「类型组合 → 结果类型」表（`int+int→int` 等），非用户可扩展 |

### 缺口范围

- 二元：`+ - * / % == != < > <= >= & | ^ << >>`
- 一元：`+ - ! ~`
- 转换：`implicit` / `explicit`
- 查找顺序：内建（原始类型）优先 → 用户定义（精确匹配起步）
- 三后端分派：C# IL（`call` 静态）/ Evaluator / Native（静态调用）
- `.co` 轨需同步（`BoundBinaryOperator` / `IlEmitter.EmitBinaryOp` 两处 `And`/`Or` 短路已就位，可复用发射框架）

### 与自举主线的关联

`.co` 语料大量使用 `+` 拼接与 `==` 比较。补齐运算符重载后，`BoundBinaryOperator` 的类型推导需区分「内建」与「用户定义」，这与阶段 8 剩余 22 处类型错配**共用同一条推断路径**，补齐可顺带加固自举 binder。

## 8. 核查方法（可复现）

> ⚠️ **纪律（血泪教训）**：本表早期版本有 **6 处**结论是错的（模式匹配语义、`record` 语法、索引器、元组、`struct` 值语义、`partial` 合并），根因都是**凭 token/kind 名称或文档标记推断功能是否存在**，而没跑代码。
> 典型：索引器被误判为"未实现"，实际只是本语言语法是 `property this[i: T]` 而非 C# 式 `property Item`；元组被误判为"无 Tuple kind 故未实现"，实际元组走 `TupleTypeSymbol` 而非独立 `SyntaxKind`。
>
> **规则：任何能力的状态以「跑探针到执行」为准，不以命名/文档为准。** 探针见
> `src/Cocoa.Cs/Cocoa.Tests/Compiler/RemainingFeatureProbe.cs`（剩余特性族，16 例）
> 与 `SmallFeatureProbe.cs`（中小特性，25 例）、`PatternMatchProbe.cs`（11 例）、`OperatorOverloadProbe.cs`（21 例）。
> 无括号 `record` 曾导致 parser 死循环——探针不仅验功能，也是 parser 健壮性的发现器。

```powershell
# 语法 kind 全量（判断某关键字是否存在）
Select-String -Path src\Cocoa.Cs\Cocoa.CodeAnalysis\Syntax\SyntaxKind.cs `
  -Pattern '^\s+([A-Za-z]\w*),?\s*(//.*)?$' | ForEach-Object { $_.Matches[0].Groups[1].Value }

# 某能力在 C# 轨的落点
Get-ChildItem src\Cocoa.Cs -Recurse -Filter *.cs | Where-Object { $_.FullName -notmatch '\\obj\\' } |
  Select-String -Pattern '<关键字或类型名>' -List

# .co 轨同构检查
Get-ChildItem src\Cocoa.Co -Recurse -Filter *.co | Select-String -Pattern '<名称>' -List

# SDK 是否提供某 facade
Get-ChildItem src\Cocoa.SDK -Recurse -Filter *.co | Select-String -Pattern 'Reflection' -List
```
