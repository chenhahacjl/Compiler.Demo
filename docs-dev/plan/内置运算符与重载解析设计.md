# 内置运算符与重载解析设计（BuiltInOperators + OperatorOverloadResolution）

> 状态：✅ 设计定稿（2026-10-09）
> 定位：对齐 Roslyn `BuiltInOperators` / `OperatorOverloadResolution` 形态，落地 C# 14 运算符语义基线。
> 相关：`src/Cocoa.Cs/Cocoa.CodeAnalysis/Binding/`、`docs/ARCHITECTURE.md`、`CODING.md` §5。

## 1. 目标

把 Cocoa 内建运算符的「规则表 + 查询 + 组合合成」从 `BoundBinaryOperator`/`BoundUnaryOperator`
的静态表重构为独立的 `BuiltInOperators` 组件，并把运算符解析从「内建命中即用 → miss 回落用户定义」
升级为「候选集（内建 ∪ 用户定义）→ applicable → better 计分」的完整重载解析，对齐 C# 14 语义（含
用户定义复合赋值 `+=`、实例 `++`/`--`、checked 运算符）。

## 2. 现状基线（2026-10 实证）

- `BoundBinaryOperator._operators`（静态表，`BuildOperators()` 程序化生成）：10 数值类型 × 多 kind +
  bool/string/char/decimal/nint/any/null/委托/??；`Bind(kind, left, right)` 线性 foreach + 6 个动态合成分支
  （enum / delegate / 类引用相等 / 函数值相等 / null 引用 / ??）。
- `BoundUnaryOperator._operators`：数值 ±/~、bool !、decimal ±。
- 用户定义重载：`OperatorRegistry`（按 OperatorKind+类型键索引 FunctionSymbol）；精确 + 交换候选；
  转换计分缺失（D1 后置债务）。
- 绑定路由：`BindBinaryExpression` = 内建命中即用 → miss 回落 `TryBindUserDefinedBinaryOperator`；
  类引用相等单开特权（用户定义优先于 ReferenceEquals）。`BoundConversion` 4 态（None/Identity/Implicit/Explicit）。
- 方法重载已有 better 计分半成品：`CompareOverloadTargets` + numeric conversion rank（表达式绑定 :2666）。
- 发射层：Evaluator / IL / native（MirToLir）深度 switch `BoundBinaryOperatorKind`，均走 `IsUserDefined` 分派。
- 符号合成先例：`BuiltinFunctions`（BuiltinSpec + `FunctionSymbol.BuiltinKind`，三后端按 BuiltinKind switch）。

## 3. 目标形态

```
Roslyn 层                → 本项目落地
规则表 + 懒加载           → BuiltInOperators.cs（Signature 数组，按 kind 索引）
GetSignature/             → 公开查询面
GetSimpleBuiltInOperators
组合合成 → 候选集          → enum/delegate/string/null 合成产候选 Signature[]
CommonCreateBuiltinOperator → BuiltinOperatorFactory（FunctionSymbol + BuiltinKind，复用 BuiltinSpec 范式）
OperatorOverloadResolution → OperatorOverloadResolver.cs（候选∪/applicable/better 计分）
```

**关键设计决策：内建运算符合成语义符号，但发射层不动（kind 直分派保留）。**
这与 Roslyn 语义一致——`int + int` 经重载解析合成 `IMethodSymbol`，但编译到 IL 仍是 `add`
指令而非 `call string.Concat`。符号是语义/反射/重载解析视图；发射仍按 kind。

## 5. 阶段 2 · 符号化语义视图

- 扩展 `BuiltinKind` 枚举：内建运算符发射键（`Add_I32`、`Eq_Str` 等按 kind×类型族）。
- 新增 `BuiltinOperatorFactory`（或并入 `BuiltInOperators.IsBuiltinOperator`）：按需合成 `FunctionSymbol`
  （`BuiltinSpec` 构造法，`BuiltinKind` 携带，`containingClass` 时内建无方法体）。
- `BoundBinaryOperator` 增可选 `BuiltinOperatorSymbol` 属性（语义视图，供反射/诊断/重载解析）。
- 发射层三后端 kind switch **一律不动**。

## 6. 阶段 3 · C# 14 增强（绑定/路由层为主）

- **复合赋值 `+=`**：`BindCompoundAssignmentExpression` 加「用户 `op_+=` 优先 → 回落脱糖 `op_+`」；
  C# 14：变量上下文 instance `void op_+=` 优先，static 回落。
- **实例 `++`/`--`**：`BindIncrementOrDecrement` 加候选：变量上下文 instance 优先；后缀 `x++` 忽略
  instance（无法确定引用类型先自增再取旧值语义）。
- **checked 运算符**：解析入口带 checked 上下文标志，`operator checked +` 优先；三后端溢出语义沿用
  既有 checked 语句支持面。
  - **范围边界（2026-10 实证）**：Cocoa 现有 `checked`/`unchecked` 仅**语句级**（`BoundCheckedStatement`，
    binder `_checkedStack`），无「运算符 checked 前缀」声明形态，亦无三后端运算符级溢出语义（native IL
    溢出检测指令缺失）。C# 11 `operator checked +` 需语法 token + 绑定候选双轨 + 发射溢出语义三层新增，
    **超出「发射层不动」红线**——列为后续独立阶段（P3 实验），本设计不承诺落地。

## 9. 与 Roslyn 的刻意差异

- 内建合成**语义符号**但发射走 kind（Roslyn `add` 语义忠实还原）；不给内建造「可被调用的方法体」。
- 该差异是「kind 即指令」架构的既定选择，不违背 Roslyn 语义等价。
