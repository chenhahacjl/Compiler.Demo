## 1. 定位与验收口径

- **目标**：Cocoa 版编译器可编译全部测试用例；Native 与 IL 两条路径都要自举。
- **阶段 8 验收**：Stage 0（C# 编译器编译 Cocoa 源码 → B0）→ Stage 1（B0 编译同一源码 → B1）→ Stage 2（B1 编译同一源码 → B2）；B1 ≡ B2 行为等价，且 B2 能编译真实项目。
- **语言约束**：只能使用阶段 6 冻结的语言能力（`src/Cocoa.Cs` 现有编译器自产自证）。
- **管线顺序**：Lexer → Syntax → Parser → Binder → Lowerer → IR → Emit（Native/IL 两条发射路径对称组织）。
- **正确性策略**：每个组件与 C# 版实现做**逐单元差分对照**（token/语法节点/绑定节点…），先严格核心、再收 trivia/边角。

## 6. 增量二：自举 Syntax/Parser（M8-a…，2026-09-13 起）

> 目标：用 Cocoa 重写递归下降 Parser（`src/Cocoa.Co/Parser/`），对照 C# `CocoaParser`（~4000 行）差分。
> 差分口径：**规范树 dump**（红树递归 `(Kind "text" children...)`）逐字节一致——C# 侧基准由 `ParserDifferentialTests.TreeDump` 生成，self-hosted Parser 产出同名结构。

### M8-a0 差分基建 ✅（2026-09-13）
- `ParserDifferentialTests.cs`：`TreeDump(SyntaxNode)`（token 带 text，复合节点带子节点，trivia 不入 dump）+ 语料基准观察（`DumpObservation_Examples` 落盘 `%TEMP%\cocoa-parser-dump.txt` 约束格式）。
- 差分目标格式已确认（示例见该文件）：CompilationUnit → FunctionDeclaration → 各 token/TypeClause/BlockStatement…。

### M8-a1 自举 Parser 骨架 ✅（2026-09-13）
- `src/Cocoa.Co/Parser/Parser.co`：Token 流（复用 `MiniLexer`）→ 递归下降 → 自举 `Node` 树（kind 名 = C# SyntaxKind 配置名）+ `Dump()` 与 C# 基准逐字节一致。
- 需 token kind 映射表：关键字 75（→`FunctionKeyword`…）+ 运算符 ~50（→`OpenParenthesisToken`…）+ 字面量（→`NumberToken`/`StringToken`/…）。
- 已支持子集：顶层 `function` 声明（参数/返回类型/块体）、`var/let` 声明、`return`、`if/else`、`while`、`for i = a to b step c`、表达式语句、二元（优先级）/一元/字面量/名字/调用/成员访问/成员调用/赋值/lambda。
