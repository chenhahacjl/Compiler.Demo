## 1. 定位与验收口径

- **目标**：Cocoa 版编译器可编译全部测试用例；Native 与 IL 两条路径都要自举。
- **阶段 8 验收**：Stage 0（C# 编译器编译 Cocoa 源码 → B0）→ Stage 1（B0 编译同一源码 → B1）→ Stage 2（B1 编译同一源码 → B2）；B1 ≡ B2 行为等价，且 B2 能编译真实项目。
- **语言约束**：只能使用阶段 6 冻结的语言能力（`src/Cocoa.Cs` 现有编译器自产自证）。
- **管线顺序**：Lexer → Syntax → Parser → Binder → Lowerer → IR → Emit（Native/IL 两条发射路径对称组织）。
- **正确性策略**：每个组件与 C# 版实现做**逐单元差分对照**（token/语法节点/绑定节点…），先严格核心、再收 trivia/边角。

3. 含 **B0 骨架**（可拆分）：用 C# 编译器把 `src/Cocoa.Co` 构建为可运行的「自举词法器」可执行文件并冒烟。

### M7-a0 组织与结构化 token 模型
- `git mv` `src/Cocoa.Cs/Cocoa.Tests/Resources/MiniLexer.co → src/Cocoa.Co/Lexer/Lexer.co`；测试改读新路径。
- 输出从「格式化字符串」改为**结构化 `Token`**（`Kind`/`Text`/`Line`/`Column`/`Offset`）+ `Describe()` 可读输出；`MiniLexerTests` 期望经 `Describe()` 保持稳定。
- ✅ 行为等价迁移，三后端绿（`0e4aa47`）。

### M7-a1 补齐 token 面（对齐 `LexerBase`/`CocoaSyntaxFacts`）
- 字符串家族：verbatim `@"…"`、raw `"""…"""`（多行缩进剥离）、插值 `$"…"`/`$@"…"`/`@$"…"`（`{{`/`}}`/洞扫描）；`@ident`。
- 数字：`0b` 二进制、`_` 分隔、后缀 `u/ul/f`（大小写）。
- 注释：`///` 文档注释与 `//` 区分；块注释未闭合 → 错误 token。
- 运算符全集（三/两字符最长匹配，对齐 `CocoaSyntaxFacts`）；关键字表对齐 `CocoaSyntaxFacts` 全集。
- 错误 token：未终止字符串/字符、非法字符、坏转义。
- ✅ 已落地（`8768eb5`）：token 面补全 + TokenSurface 测试（6 测试 ×三后端）。

### M7-a2 差分测试（正确性护栏）
- `LexerDifferentialTests`：语料 = `samples/` 下全部 `.co`（33 个文件）+ 内嵌边界用例（11 组：字符串家族/字符/数字/运算符/非法字符/注释/关键字全集）。
- 自举 Lexer 与 C# `CocoaLexer` **非 trivia 逐 token 严格比对**（kind 映射名 / offset / len / 行列）；失败打印首个分歧 token 上下文。
- ✅ **2026-09-13 全部语料逐 token 一致**（44/44）。测试即捕获真实缺陷：raw 字符串闭合回退 `_pos = runStart + delimiter` 未同步 `_col`（`""""raw4""""` 后 token 列偏 +1），已修。

### M7-a2b 本轮 trivia 差异清单（下一增量收紧，本轮不断言）
