# 产物元数据节（`.cocoa`）设计

> 规划标记：🧭 定稿（2026-10-08）
> 定位：给 native 产物内嵌 `.cocoa` 自定义 PE 节，以 `"COCOA"` 魔数 + 多流二进制格式保存 Cocoa 完整符号表，供工具链与运行期自省。
> 状态：📋 设计定稿，实施 M1~M7 推进中（见进度）；与 `.coa`（库文本语义层）并存、各司其职。
> 相关：[`docs-dev/开发计划.md`](../开发计划.md)、[`docs/编译手册.md`](../../docs/编译手册.md)、`docs/ARCHITECTURE.md`

## 1. 目标与背景

native 产物（native + IL 路径）内嵌 **`.cocoa` 自定义节**，以**参照 ECMA-335 的元数据根 + 多流**二进制格式保存 **Cocoa 完整符号表**（类型/方法/字段 + 属性 + 文档），供**工具链自省**与**运行期自省**两端读取。解决 native 产物无元数据（属性/符号/反射信息无处放）的痛点。

## 2. 全部决策（锁定）

| 维度 | 决策 |
|---|---|
| 节名 | `.cocoa`（6 字符，PE 节名 8 字节上限内） |
| 魔数 | `"COCOA"`（5B ASCII，与 `.coa` 库魔数一致；全仓 Cocoa 语义/元数据统一） |
| 内容 | 完整符号表（类型/方法/字段 + 属性 + 文档 + 依赖） |
| 写入端 | **仅 native 产物**（IL 不加——避免与 CLR 元数据双份源漂移；IL 读回走 CLR 元数据） |
| 元数据根 | **两个独立根**：ECMA-335 `BSJB` 根（IL 现用，不动）；`.cocoa` 另立 `"COCOA"` 根 + 自定义流头，仅共享「流头 + 偏移」通用小工具 |
| 表行引用 | **行号交叉引用**（定宽表行；字符串/实参经堆偏移；类行号→方法行号） |
| 属性实参 | **对齐 CLR CustomAttribute Value blob**（ECMA-335 定长/变长编码） |
| 符号来源 | **发射后实际符号集**（`MirToLir._liveClasses` + `_functionMap`，含 lambda 环境类/单态化泛型展开/自动属性后备字段；native 后端需补公开快照出口） |
| 运行期自省 | **内存自省**：`GetModuleHandle(NULL)` → 自身镜像基址 → 内存节表 RVA 换算 → 读内存中 `.cocoa` 节 |
| 体积策略 | **默认强制内嵌**（全 native exe；体积增加接受，后续可考量 strip 选项） |
| 读取端 | 工具链（`cocoa inspect`）+ 运行期自省，两者都要 |
| 实施 | M1 裸根先行 · 只 C# 侧（`.co` 镜像后续增量五/阶段 8） |

## 3. 存储布局（`.cocoa` 根）

```
.cocoa 节 = CocoaMetadataRoot
  [0x00] 魔数 "COCOA" (5B, ASCII)
  [0x05] 版本  (1B)
  [0x06] 标志  (2B, 预留)
  [0x08] 流数  (2B)
  [0x0A] 流头表：N × (name[8] | offset:u32 | size:u32)
         offset 相对 .cocoa 根起点
  ...    各流数据
  #Types    类型表（类/枚举/结构：定宽行 + 属性行号引用 + name 堆偏移）
  #Methods  方法表（签名、行号交叉引用、name 堆偏移）
  #Fields   字段表
  #Attrs    属性表（属性类型全名 + CLR 风格实参 blob 引用）
  #Strings  字符串堆（去重，name/文档 偏移引用）
  #Blob     CLR 风格属性实参 / 签名 blob 堆
  #Docs     文档串（DocID → 原文）
```

## 4. 分层架构

```
L1 统一结构类层（Cocoa.CodeGen.PE）
   MetadataRootWriter / MetadataRootReader —— 通用「魔数 + 流头 + 偏移」小工具：
     · IL 的 BSJB 根：ManagedPEWriter 现用（Emit 保持不动，字节兼容）
     · .cocoa 的 COCOA 根：复用同一套流头/偏移读写逻辑
   PeImageStructure（容器：DosHeader + NtHeaders + 节表 + 各节）+ Save/ToArray/Read（复用 PeHeaders record）

L2 .cocoa 节 = CocoaMetadataRoot（native 产物内嵌，`PeSectionSpec(".cocoa", rootBytes, ...)`）

L3 读取端
   工具链：cocoa inspect <exe> → 按节表定位 .cocoa → CocoaMetadataReader → 打印符号/属性
   运行期：native 内存自省（get-module-base → 内存节表 → 读自身 .cocoa）
```

## 5. 实施里程碑

| 里程碑 | 内容 | 验收 |
|---|---|---|
| M1 | 通用 `MetadataRootWriter/Reader`（任意流集 + 偏移引用）+ 裸根 round-trip 单测（写→读逐字节一致） | 独立单测绿；IL `ManagedPEWriter` 不动 |
| M2 | native 后端「发射后符号快照」公开出口（`_liveClasses`/`_functionMap` → 可枚举公开 API） | 后端暴露测试 |
| M3 | `CocoaMetadataBuilder/Reader`：快照符号 → 四表 + 双堆 + Docs（行号引用 + CLR 属性 blob）→ 反序列化回表 | round-trip 覆盖 类型/方法/字段/属性/文档 |
| M4 | native 写侧嵌入 `.cocoa` 节 | 产物含节；PE 差分 / e2e 绿 |
| M5 | 工具链 `cocoa inspect <exe>`（新子命令）读回打印 | e2e：inspect 打印属性/符号 |
| M6 | 运行期内存自省（native get-module-base → 读自身节） | native 冒烟 |
| M7 | 文档（编译手册命令 + 本稿定稿）+ 全量回归 | — |

## 6. 边界与风险

- `.coa`（库文本格式）**不动**；`.cocoa`（产物内嵌二进制）是新增自省载体，两者并存。
- M1 抽取 MetadataRoot 需保证 `ManagedPEWriter` 行为不变（回退兼容，靠既有 IL/PE 差分测试）。
- M2 触碰 native 后端内部（`MirToLir`），是主要风险点——符号快照出口须纯暴露不加逻辑，发射路径零改动。
- native 运行期定位 `.cocoa` 依赖原生节表解析 + get-module-base（M6）。
- 属性实参对齐 CLR CustomAttribute blob 编码，读回忠实还原。

## 8. 外部可见性：COFF 调试符号与杀软白面（2026-10-19 定稿）

`.cocoa` 是内部自省/工具链载体；**对外部工具（IDA/dumpbin/WinDbg）**，native 产物另配经典 COFF 调试信息，让函数符号与源行号可直接读，**不依赖 PDB 文件**。

- **COFF 符号表**：`CoffSymbolTableBuilder` 产出 IMAGE_SYMBOL 记录（函数符号名 → RVA，节 1=.text）+ `.text` 节符号（节定义 aux + IMAGE_LINENUMBER 行号 aux，函数入口粒度：文件:行）+ FILE 符号（源文件）+ 字符串表；经 `PeObjectWriter` 追加到节原始数据之后，回填文件头 `PointerToSymbolTable` / `NumberOfSymbols`（记录总数 = 主符号 + aux）。
- **符号来源**：`EmittedSymbolSnapshot.Functions`（实际发射函数）+ `result.Labels`（LIR 名 → 标签 → RVA）+ `FunctionSymbol.Declaration ?? Syntax` 的 `TextLocation`（`FileName` + `StartLine`，1-based）。
- **行号粒度**：COFF 与原生 PDB 的 `S_LINES` 均为函数入口粒度（每条对应一个函数起点）；语句/指令级行号需把 SyntaxTree 行信息穿透到 MIR/LIR，列为后续。
- **无 PDB 决策（已更新）**：曾因"广告不存在的 .pdb"移除 RSDS；现真实 PDB 已生成（原生 PDB 7.0 内 `S_GPROC32`+`S_LINES` 承载函数符号与行号，旁置 `<模块>.pdb`），exe 重加 Debug/RSDS 指向之；COFF 符号表保留作无 PDB 时的兜底。
- **AV 白面（同批）**：Rich 头（自定义产品/构建 ID，`e_lfanew=0x100`）+ 导入表自包含 `.idata`（dir1/dir12/FirstThunk 全落 `.idata`，IAT 镜像 INT——Windows 加载器对 0 槽按 bound-import 跳过，实测 0 槽 `.data`/`.idata` 均崩）+ `.cocoa` 节末位 + 默认图标内嵌（EmbeddedResource）+ 版本元数据缺省值（`FileDescription` 回落 `AssemblyName`）+ 共享运行库随产物目录部署。

## 9. Portable PDB（IL 产物，2026-10-19）

IL（dotnet/VS）产物的调试符号走 **Portable PDB（ECMA-335）**，与 native 的 COFF/PDB 7.0 并行：

- **生成**：`IlEmitter.Emit` 写出 PE 后用 `System.Reflection.Metadata.PortablePdbBuilder` 旁置 `<模块>.pdb`——Module 行 MVID 取产物自身（PEReader 回读），Document 表按源文件去重，MethodDebugInformation 表按方法 MethodDef RID 挂文档。
- **序列点（语句级）**：发射期在 `EmitStatement` 捕获（语句首个指令在 `IlAssembler.Instructions` 的下标 + `BoundNode.Syntax.Location` 的文件/行），`Assemble()` 回填 `IlInstruction.Offset` 后换算字节偏移；序列点 blob 手编（net9.0 SRM 无 `SequencePointEncoder`），格式对齐 dotnet/runtime `SequencePointCollection.Enumerator`：header(localSignature) → 首点绝对偏移/绝对行 → 后续点增量偏移/增量行；可见点发 deltaLines=0+deltaColumns=1（(0,0)=hidden）；文件变更发 0x00+文档行号；无终止符。SRM 读取器 `GetSequencePoints()` 回读验证。
- **注意事项**：PortablePdbBuilder 第 2 参为产物各 ECMA 表行数（64 项 `ImmutableArray<int>`）；net9.0 内嵌 SRM 无 `SequencePointEncoder`/`PortablePdbVersions`（故不依赖之）；读取验证用 `MetadataReaderProvider.FromPortablePdbStream`（便携 PDB 非 PE 镜像）。
