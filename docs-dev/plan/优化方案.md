## 0. 背景与定稿决策

对 15 个工程、约 14 万行 C# 做逐项核查（含命名空间、编码、重复逻辑的实测）后，形成本方案。五轴：项目架构 / 文件结构 / 项目命名 / 代码命名 / 内容质量。

**已锁定的治理决策**（用户评审，2026-10-17）：

| 决策 | 结论 |
|------|------|
| partial 文件命名 | 统一 **点号** `Type.Role.cs`（对齐 CODING.md §6） |
| 类级 `Cocoa` 前缀 | **去掉**（与其余 `Syntax*`/`Green*` 类型一致；`CocoaBinder` 例外另议） |
| 执行顺序 | `A → B → C`，其中 **C1（内建去重）置顶** |
| 文档先落 | 本文件先行入库 |
| PE 资源/版本 DTO（C3） | **纯移动**到 `Core/…/Emit/`，**不建** `PeMetadata`/`ElfMetadata` |
| `Cocoa.Engine` 归位（C4） | 新建 **`Hosting/`** 工程分类 |
| 测试工程命名（B6） | `Cocoa.Tests.Compiler` → `Cocoa.Tests.Integration`；Engine 测试拆出 `Cocoa.Tests.Engine` |
| 外部消费者（B7） | `Cocoa.IDE` / `samples/Scripting/CsHost` **纳入并保持可编译** |
| 文档失效引用 | `docs/` 与 `docs-dev/` **全量修正** |

## 1. 问题总账

### 1.1 项目架构
- **跨后端重复实现**：`BuiltinKind` 分派 3 处（`Evaluator.Calls.cs` / `MirToLir.Builtins.cs` / `IlEmitter.Expressions.cs`）；`System.Object`/`Type` 成员语义 4 处；`Align4`/`WriteUInt*` 3 处（`PeBinary.cs` 已抽取但未铺开）。
- **`Cocoa.Targeting` 杂物袋**：混 target 常量 / 托管目标模型 / native ABI 描述符 / 对象写出器接口 / DLL 解析策略；两套并行目标模型（`TargetPlatform` 253 引用 vs `TargetTriple` 11 引用）；`TargetAbi` 死枚举；`Architecture`/`Cpu` 双枚举；`SupportedTargets` 虚假声明 macos。
- **`Cocoa.Cli/Program.cs` 上帝类**（507 行）；`-i` 判断重复 3 处（其中 2 处不可达）；`inspect` 未入 help。
- **`Cocoa.Engine` 误置 `Tools/`**（嵌入式脚本宿主 API 库，仅测试引用）。

### 1.2 文件结构
- **命名空间与目录不一致**：`Bound/**`（77 文件，平铺 `…Bound`）；REPL `Services|Terminal` 塌缩；测试 `Compiler/`、`CodeGen/` 目录段被丢。
- **`Cocoa.CodeAnalysis/Text/` 命名冲突**：仅 1 个 `TextWriterExtensions.cs`，与真实文本层工程 `Cocoa.Text` 同名不同物。
- **超大文件未拆**（>2000）：`CocoaBinder_Expressions.cs`(3261)、`CocoaGreenNodeFactory.cs`(2043)；`RuntimeFunctionEmitter` 主声明在 `RuntimeEmitterLir.cs`。
- **多类型同文件**：`IObjectWriter.cs`→`ObjectWriteOptions` 等 6 处。

### 1.3 项目命名
- `Cocoa.Tests.Compiler` 名不副实（含 Build/Engine 测试）。
- `Cocoa.Tests.CodeGen` 与 4 个 `Cocoa.CodeGen.*` 产品工程非 1:1。
- 残留改名痕迹：`bin` 下 `*.Lir.dll`/`*.Writer.dll`；`ManagedBackend.cs` 注释“Cocoa.CodeGen.IL”。

### 1.4 代码命名
- partial 两种风格（下划线 20 个 / 点号 22 个）并存。
- 类级 `Cocoa` 前缀仅 4 类带；文件名≠类型名 4 处（`EvaluatorRuntime.cs`→`EvaluatorObject` 等）；测试 `*Probe.cs`(12) 实为普通测试；`IL/` 目录 vs `Il` 命名；`IIlRefIssuer` 双 I。

### 1.5 内容质量
- **编码损坏**：`Cocoa.Tests.CodeAnalysis/BackendRegistration.cs:10`、`CocoaGreenNodeFactory.cs:8`、`DumpCommand.cs:10-11`（含真实 U+FFFD）、`.gitignore`、多处脚本注释。
- **失效脚本（半迁移）**：`build.cmd|sh`、`cocoa.cmd|sh`、`repl.cmd|sh`、`tools/build-co|cs|ui.cmd`、`tools/run-tests-dev.cmd` 指向不存在的 `Cocoa.Tests` / `Cli\Cocoa.Cli`；`build-sdk.cmd` 已修但兄弟未跟进。
- **失效路径**：`CsHost.csproj:18`、`docs/嵌入式引擎API.md:34`、`docs/编译器手册.md:72`。
- **过度 public API**：ObjectFormat 73 个 public 类型（含 11 个零引用 PE 结构体）；Native LIR 全 public（52 类型 / 617 成员）而仅测试消费。
- **复制粘贴**：`CocoaLexer.cs:11-30` 同一 `<summary>` 连写 4 遍；`SubsystemPEEmitTests.cs` 压成一行；`BuiltinFunctions.cs` 三表人肉同步。
- **外部消费者**：`src/Cocoa.IDE`（独立 slnx，7 处 `Cocoa.CodeAnalysis.Text` + Targeting）与 `samples/Scripting/CsHost`；IDE 预存破损（`Cocoa.CodeAnalysis.Text.SourceText` 实际在 `Cocoa.Text`）。

**正面对照**：TODO/FIXME/HACK 极少（3 个 TODO）、无注释掉的死代码、目录 4 分类清晰。

## 2. 执行清单

> 标记：⬜ 待办 / 🔄 进行中 / ✅ 完成。每步独立 commit（`refactor(...)`/`docs(...)`），步骤内同步相关文档。

### 第 0 步 — 方案入库
- ✅ 本文件 + `docs-dev/README.md` 挂链 + `CODING.md` 更新（§2 工程表 / §6 命名 / Core 命名空间例外说明）。

### A — 低风险清理（零行为改动）
- ⬜ A1 编码修复：**阻塞**——HEAD 中乱码为逐行混杂，自动反转会误伤正确行，用户决定跳过后执行 A2–C（详见遗留支线）。
- ✅ A2 粘贴/格式：`CocoaLexer.cs` 重复注释、`BuiltinFunctions.cs` 缩进、`SubsystemPEEmitTests.cs`、`Cocoa.CodeAnalysis.csproj` 缩进。
- ✅ A3 陈旧残留：清 bin 陈余 dll；`ManagedBackend.cs` 注释。
- ✅ A4 全仓路径/脚本修复（脚本群 + `CsHost.csproj` + `docs/编译手册.md` + `docs/嵌入式引擎API.md`）。

### B — 命名 / 结构统一
- ✅ B1 partial → 点号（20 文件，`git mv`）+ 同步文档。
- ✅ B2 收窄版命名空间对齐（REPL `Services|Terminal`；测试目录段 → 并入 B6）；Core `Compilation/Diagnostic/Bound` 保持不动并登记例外（✅ CODING.md §6.1）。
- ✅ B3 `Cocoa.CodeAnalysis/Text/` → `Extensions/`（含 IDE using 同步）。
- ⬜ B4 去类级 `Cocoa` 前缀 + 杂项：✅ `Lexer`/`Parser`/`GreenNodeFactory` 去前缀 + `CocoaBinder` 登记例外；✅ `IIlRefIssuer`→`IlRefIssuer`；✅ `IL/`→`Il/`；⬜ `*Probe*`→`*Tests`、文件名≠类型名（低价值，暂缓）。
- ✅ B5 拆巨型文件：`RuntimeFunctionEmitter` 主声明归位 `RuntimeFunctionEmitter.cs`；`CocoaBinder.Expressions`/`GreenNodeFactory` 拆分暂缓（与 CODING.md 记录的单文件合并决策冲突，低价值）。
- ✅ B6 测试工程改名/拆分：`Cocoa.Tests.Compiler`→`Cocoa.Tests.Integration`（含 `Compiler/` 目录段命名空间对齐）+ 新 `Cocoa.Tests.Engine`。
- ✅ B7 外部消费者同步：`Cocoa.IDE` 预存破损修复（`CodeBackend.DotNet`→`ManagedFx/ManagedNet`、`CocoaProjectFile.Platform`→`Cpu`）；`CsHost` 引用路径已修（A4）。

### C — 架构重构
- ⬜ C1 内建去重（`BuiltinDescriptor` 表 / Object-Type 语义 / byte-writer）。安全网 `ThreeBackend` + 自举套件。
- ⬜ C2 Targeting 收敛（删 `TargetAbi` / 合并目标模型 / 统一枚举 / 修 macos 声明 / ABI 契约下移）。
- ✅ C3 PE DTO 纯移动 → `Core/…/Emit/`（不建新工程）。
- ✅ C4 `Cocoa.Engine` → `Hosting/`。
- ✅ C5 CLI 拆解（`CompileCommand.cs` / 去死 `-i` / help 补 `inspect`）。
- ⬜ C6 收敛 public API（Native LIR / 未用 PE 结构体）。
