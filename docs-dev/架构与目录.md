# 仓库结构与目录约定

> 阶段 7 结构整理（2026-09）的约定快照：Cocoa.Cs 分层、CoaFormat 子命名空间、
> docs/docs-dev 分层、tools 部署目录。随着重构继续演进时回填本页。

## 顶层

```
.
├── docs/        冻结语言规范（语法/标准库 API/项目格式等，改动需走评审）
├── docs-dev/    开发计划 / 重构执行计划 / 结构约定（本页）——活跃，随意改
├── samples/     示例（cosln/库/教程）
├── src/
│   ├── Cocoa.Cs      C# 参考编译器（本页主体）
│   ├── Cocoa.Co      Cocoa 自举编译器（自举目标，用阶段 6 冻结语言编写）
│   ├── Cocoa.SDK     标准库（System.Core 单模块，从 .co 编译为 System.Core.coa）
│   ├── Cocoa.UI      UI 库（System.UI.coproj → System.UI.coa）
│   └── Cocoa.IDE     IDE（独立 slnx）
└── tools/        构建脚本 + 产物仓（见下）
```

## Cocoa.Cs 项目与依赖

入口：`src/Cocoa.Cs/Cocoa.slnx`（12 项目）。

```
Cocoa.Targeting（叶子：IlTarget/TargetPlatform）
Cocoa.CodeGen.Managed.Structure（叶子：IL 模型）
Cocoa.CodeGen.Native.Lir（叶子：LIR 模型）
Cocoa.CodeAnalysis（前端 = Cocoa.CodeAnalysis.* 命名空间；文件夹/程序集名与命名空间对齐，结构整理 2026-09）
  ├─ CodeGen.Managed.Reader / Managed.Structure / Targeting
CodeGen/
  ├─ Cocoa.CodeGen.Interpreter → Cocoa.CodeAnalysis
  ├─ Cocoa.CodeGen.Managed.Writer → Compiler + PE + Managed.Structure/Reader
  ├─ Cocoa.CodeGen.Native → Compiler + PE + Native.Lir
  └─ Cocoa.CodeGen.PE → Targeting
Cocoa.Build → Compiler + Managed.Writer + Targeting
Cli/Cocoa.Cli（exe `cocoa`）、Cli/Cocoa.Cli.Repl
Cocoa.Tests（引用全部）
```

分层约定：**前端（前端=编译器）只引用叶子**；**后端（CodeGen/Interpreter/Writer/Native）引用前端拿符号/绑定树**；
`Cocoa.Build`/`Cli` 组装；`Cocoa.Tests` 引用一切（测试根）。

## Cocoa.CodeAnalysis 子目录（Roslyn 式）

`Syntax/`（红节点 + Lexer + Parser）、`Syntax/Green/`（绿节点 + 绿工厂 + SyntaxFactory）、
`Syntax/Nodes/`（红节点每类一文件）、`Binding/`、`Bound/`、`Compilation/`、`Diagnostic/`、
`Documentation/`、`Lowering/`、`Serialization/`

- **绿节点**（GreenNode 族，internal）与**生产它们的工厂**同居 `Syntax/Green/`；公开红语法基类 `SyntaxNode`/`RedNode` 住 `Syntax/` 根。
- `CocoaGreenNodeFactory` 为 `partial`：`Green/CocoaGreenNodeFactory.cs`（派发）+ `.Expressions.cs`/`.Statements.cs`/`.Members.cs`。

## Serialization 与 CoaFormat 子命名空间

`Serialization/` 外层只留**门面** `CoaSerializer`（`Write`/`Read`/`Load` + Magic/Version）与数据类型
（`CoaProgram`/`CoaRequirement`/`CoaAssemblyNaming`/`SystemLibrary`）。

格式实现全部在 **`Serialization/CoaFormat/`**（`Cocoa.CodeAnalysis.Serialization.CoaFormat`），无 partial、无巨型单类：

| 类 | 形态 | 职责 |
|---|---|---|
| `CoaFormatWriter` | sealed（实例） | 写端协调：`_output`(CoaTextWriter) + `_registry`(CoaRegistry)，Emit*/Write* 全实例 |
| `CoaFormatReader` | sealed（实例） | 读端协调：`_tokens`(CoaTextReader) + `_context`(CoaReadContext) + `_resolver`(CoaTypeResolver)，Read* 全实例 |
| `CoaRegistry` | sealed（实例） | 写侧登记/命名；`Emitters = List<Action<CoaFormatWriter>>` |
| `CoaTypeResolver` | sealed（实例） | 读侧类型/键解析（跨库 external 合并） |
| `CoaTextWriter`/`CoaTextReader` | sealed（实例） | 文本写出/读入；`ReadLabeledField`/`ReadCountField`/`ParseBoolWord` 收敛为 CoaTextReader 实例方法 |
| `CoaReadContext` | sealed（实例） | 读侧共享符号表 |
| `CoaText` | static | 值编解码、转义、布尔词形、checksum、manifest 名词（纯函数） |
| `CoaTypeText` | static | 类型→文本（TypeRef/LibraryQualify/EncodeInstantiatedTypeRef/sort key） |

约定：**协调器实例化、纯编解码静态**；递归方法只传按函数作用域的 `labels`，不显式传上下文。
coa 文本词形单一：bool 一律 `true`/`false`；参数修饰符 `out:`/`ref:`/`-`；"无值"一律 `/0`。

## docs/ 与 docs-dev/ 分层

- `docs/`：**冻结**的语言规范（语法规范、标准库 API 参考、项目格式规范、文档格式规范等），改动走评审。
- `docs-dev/`：**活跃**开发文档（开发计划、执行计划、里程碑盘点、结构约定），随手改。

## tools/ 与产物仓

- `build-{cs,sdk,ui,ide,co}.cmd`：构建对应目标。
- `cocoa-{cs,sdk,ui,ide,co}/`：**gitignored** 部署产物仓（System.Core.coa / Cocoa.Cli.exe / Cocoa.Compiler.coa 等）。
- `udl/`：Notepad++ 语法高亮（UDL XML）。
- 中央库仓：`src/Cocoa.Cs/libs/System.Core.coa`（`Directory.Build.targets` 自动分发到各项目输出）。
