## P1-1：FunctionSymbol/NamedTypeSymbol Declaration → SyntaxNode?

**目标**：符号 `Declaration` 属性与构造参数由语言具体类型改语言中性 `SyntaxNode?`（共享具体节点是 `SyntaxNode` 子类，天然兼容），为语言节点替换铺路。

**改动**：
- `Cocoa.Core/Symbols/FunctionSymbol.cs`：ctor 参数 + `Declaration` 属性 `FunctionDeclarationSyntax?` → `SyntaxNode?`
- `Cocoa.Core/Symbols/NamedTypeSymbol.cs`：ctor 参数 + `Declaration` 属性 `ClassDeclarationSyntax?` → `SyntaxNode?`
- 消费者适配（仍持共享具体节点，作共享类型转换保持行为不变）：
  - `Cocoa.Core/Compilation/Compilation.cs`（3 处 `Declaration?.Identifier.Location` → `((ClassDeclarationSyntax?)…)?`）
  - `Cocoa.Core/Emit/Native/NativeImportValidator.cs`（2 处 + 补 `using Cocoa.CodeAnalysis.Syntax`）
  - `Cocoa.Core.Cocoa/Binder/Impl/CocoaBinder.cs` / `Cocoa.Core.CSharp/Binder/Impl/CSharpBinder.cs`（`Declaration.Body`/`.Identifier`/`.Identifier.Location` 共 8 处）
