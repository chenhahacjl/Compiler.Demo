# Cocoa.IDE — Cocoa 语言 IDE（规划中，占位）

> 状态：**规划中，形态未定**（2026-08-23 排上日程）。
> git 不跟踪空目录，故先落此说明。

## 候选路线

| 路线 | 说明 | 优劣 |
|------|------|------|
| **LSP 服务器** | 用 C# 基于 `Cocoa.Core` 写 Language Server（进程内复用完整编译管线），任何编辑器经标准协议接入 | 现代语言工具链标准做法；诊断/hover/补全直接来自真实绑定树，零重复实现 |
| **自研桌面 IDE** | WPF / Avalonia 图形界面，进程内集成编译器 | 完整掌控体验；工程量最大 |

无论哪条路线，均要求编译器对外暴露稳定的**增量绑定/诊断 API**——因此排期位于对象模型与泛型里程碑之后。

## 历史基线（功能对齐清单）

曾有一个 VS Code 扩展（进程内正则符号表方案，无 LSP，2026-08-23 移除），提供过以下能力，作为未来 IDE 的功能下限参考：

1. 语法高亮（`.co` 文件）
2. 代码补全
3. Hover 信息
4. 跳转到定义
5. 查找引用
6. 签名帮助
7. 文档符号大纲

> 注意：旧方案基于正则扫描，未使用编译器真实语义。新路线的核心优势即"语义精确"。

## 排期约束
